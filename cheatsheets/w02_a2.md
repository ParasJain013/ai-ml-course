# Week 02 cheat sheet: A2 Linear algebra I: matrices

## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Matrix–vector (row view) | $(\mathbf{A}\mathbf{x})_i = \sum_j A_{ij}x_j$ | `(m, d) @ (d,)` → `(m,)` |
| Matrix–vector (column view) | $\mathbf{A}\mathbf{x} = x_1\mathbf{a}_1 + \dots + x_d\mathbf{a}_d$; $\mathbf{A}\mathbf{e}_j = \mathbf{a}_j$ | columns = images of $\mathbf{e}_j$ |
| Many points (rows) | $\mathbf{X}\mathbf{A}^\top$ | `(n, d) @ (d, m)` → `(n, m)` |
| Product | $(\mathbf{A}\mathbf{B})_{ij} = \sum_p A_{ip}B_{pj}$; "do $\mathbf{B}$, then $\mathbf{A}$" | `(n, d) @ (d, k)` → `(n, k)`, cost $ndk$ |
| 2×2 determinant | $ad - bc$ = signed area scale; 0 ⇒ singular | scalar |
| 2×2 inverse | $\frac{1}{ad - bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$ | `(2, 2)` |
| Reversal rules | $(\mathbf{A}\mathbf{B})^\top = \mathbf{B}^\top\mathbf{A}^\top$, $(\mathbf{A}\mathbf{B})^{-1} = \mathbf{B}^{-1}\mathbf{A}^{-1}$ | |
| Rotation by $\theta$ | $\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}$, det 1 | `(2, 2)` |
| Solutions of $\mathbf{A}\mathbf{x} = \mathbf{b}$ | none if $r([\mathbf{A}\mid\mathbf{b}]) > r(\mathbf{A})$; one if $= d$; else $\infty$, $d - r$ free | |
| All solutions | $\mathbf{x}_p + \mathbf{n}$, $\mathbf{A}\mathbf{n} = \mathbf{0}$ | null space dim $d - r$ |
| Projection onto a line | $\mathbf{p} = \frac{\mathbf{a}^\top\mathbf{b}}{\mathbf{a}^\top\mathbf{a}}\mathbf{a}$, $\mathbf{r} \perp \mathbf{a}$ | `(n,)` |
| Projection onto columns | $\mathbf{A}^\top\mathbf{A}\mathbf{c} = \mathbf{A}^\top\mathbf{b}$; $\mathbf{P} = \mathbf{A}(\mathbf{A}^\top\mathbf{A})^{-1}\mathbf{A}^\top$, $\mathbf{P}^2 = \mathbf{P} = \mathbf{P}^\top$ | $\mathbf{P}$ `(n, n)` |
| Normal equations | $\mathbf{X}^\top\mathbf{X}\mathbf{w} = \mathbf{X}^\top\mathbf{y}$ minimize $\lVert\mathbf{y} - \mathbf{X}\mathbf{w}\rVert^2$ | $\mathbf{X}^\top\mathbf{X}$ `(d, d)` |
| Line fit | $\begin{pmatrix}n&\sum x\\\sum x&\sum x^2\end{pmatrix}\mathbf{w} = \begin{pmatrix}\sum y\\\sum xy\end{pmatrix}$ | passes through $(\bar x, \bar y)$ |

## Code
```python
Y = X @ A.T                                    # apply A (m, d) to every row of X (n, d)
np.einsum("ij,nj->ni", A, X)                   # same thing, indices spelled out
x = np.linalg.solve(A, b)                      # square, full rank; never inv(A) @ b
r = np.linalg.matrix_rank(A)                   # SVD-based, with a tolerance
w, *_ = np.linalg.lstsq(X, y, rcond=None)      # least squares; min-norm if rank-deficient
X = np.column_stack([np.ones_like(x), x])      # design matrix with intercept, (n, 2)
w = np.linalg.solve(X.T @ X, X.T @ y)          # normal equations (small, well-scaled only)
LinearRegression().fit(x.reshape(-1, 1), y)    # adds the intercept itself
np.testing.assert_allclose(A @ x, b, rtol=1e-6, atol=1e-8)
```

## Defaults and rules of thumb
- Data is `(n, d)`, rows are examples; transform with `X @ W` (`W` `(d, k)`) or `X @ A.T`.
- Write the shape in a comment on every line that changes it; test with non-square shapes.
- Read `A @ B @ x` right to left; bracket for the smallest intermediate: `A @ (B @ x)`.
- `solve`, not `inv`; `lstsq` for rectangular or rank-deficient systems.
- Elimination uses partial pivoting (largest pivot); tolerances, never `== 0`.
- After any regression fit, plot residuals against fitted values and each feature.
- Rank of a product ≤ smallest inner size; `(n, d)` has rank ≤ min(n, d).

## Pitfalls
- Missing `.T` on a square matrix: runs, wrong map. `(d, n)` data with $n = d$: runs, wrong rows.
- `*` is elementwise, `@` is matrix product; both run on square arrays.
- $\mathbf{A}\mathbf{B} \ne \mathbf{B}\mathbf{A}$; $(\mathbf{A}\mathbf{B})^\top \ne \mathbf{A}^\top\mathbf{B}^\top$.
- `solve` raises `Singular matrix` even when infinitely many solutions exist.
- One-hot for every category + intercept → dependent columns → singular $\mathbf{X}^\top\mathbf{X}$.
- No pivoting with a tiny pivot → garbage. Forming $\mathbf{X}^\top\mathbf{X}$ squares the condition number.
- Squared loss: one huge outlier can drag the whole fit. Forgetting the ones column forces the fit through 0.

## Interview one-liners
- **Linear map:** keeps the origin, straight lines and even spacing; fully described by its columns.
- **Matrix product:** composition of maps; not commutative, associative.
- **Determinant:** area/volume scale factor; 0 means information is lost.
- **Inverse:** undoes a map; exists iff square and full rank; compute solves, not inverses.
- **Rank:** number of independent columns = dimension of what the map can reach.
- **Least squares:** project $\mathbf{y}$ onto the column space; residual ⟂ every feature column.
