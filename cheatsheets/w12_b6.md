## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Centred cosine (user CF) | $c_{ui} = r_{ui} - \bar r_u$ (0 if missing); $s_{uv} = \frac{\mathbf{c}_u\cdot\mathbf{c}_v}{\lVert\mathbf{c}_u\rVert\lVert\mathbf{c}_v\rVert}$ | $\mathbf{S}$ `(n_users, n_users)` |
| CF prediction | $\hat r_{ui} = \bar r_u + \sum_{v\in N_m} s_{uv}c_{vi}/\sum_{v\in N_m}\lvert s_{uv}\rvert$ ($m$ most similar raters of $i$) | |
| Bias model | $\hat r = \mu + b_u + b_i$; damped $b_i = \sum(r - \mu)/(\lambda_i + n_i)$ | |
| MF | $\hat r_{ui} = \mu + b_u + b_i + \mathbf{p}_u\cdot\mathbf{q}_i$; $J = \sum_{\Omega}[e^2 + \lambda(b_u^2 + b_i^2 + \lVert\mathbf{p}_u\rVert^2 + \lVert\mathbf{q}_i\rVert^2)]$ | $\mathbf{P}$ `(n_users, k)`, $\mathbf{Q}$ `(n_items, k)` |
| MF SGD step | $e = r - \hat r$; $b \mathrel{+}= \eta(e - \lambda b)$; $\mathbf{p}_u \mathrel{+}= \eta(e\mathbf{q}_i - \lambda\mathbf{p}_u)$; $\mathbf{q}_i \mathrel{+}= \eta(e\mathbf{p}_u - \lambda\mathbf{q}_i)$ (old values) | `(k,)` |
| Implicit MF | $P(y = 1) = \sigma(b_i + \mathbf{p}_u\cdot\mathbf{q}_i)$, log loss; replace $-e$ by $\sigma(z) - y$; negatives sampled per epoch | |
| P@k, R@k | $\frac{\#\text{rel in top }k}{k}$, $\frac{\#\text{rel in top }k}{\lvert\mathcal{R}\rvert}$ | |
| AP@k, MRR | $\frac{1}{\min(k, \lvert\mathcal{R}\rvert)}\sum_{j\le k}\mathrm{P@}j\,\mathbb{1}[\text{hit at }j]$; MRR = mean of $1/\text{rank of first hit}$ | |
| NDCG@k | $\mathrm{DCG} = \sum_{j=1}^{k}\mathrm{rel}_j/\log_2(j + 1)$; ÷ IDCG of **all** relevant items sorted | |
| Additive decomposition | $y_t = \mathrm{trend}_t + s_t + r_t$; trend = 2×$m$ MA, weights $\frac{1}{2m}, \frac1m, \dots, \frac1m, \frac{1}{2m}$ ($m + 1$ terms) | |
| Baselines | naive $y_T$; seasonal naive $y_{T+h-m}$; MA $\frac1m\sum_{j<m}y_{T-j}$ | |
| Skill, MASE | $1 - \mathrm{MAE}/\mathrm{MAE}_{\text{snaive}}$; MASE = MAE ÷ in-sample seasonal-naive MAE | |
| SES | $\ell_t = \alpha y_t + (1 - \alpha)\ell_{t-1}$; weights $\alpha(1 - \alpha)^j$; $\hat y_{T+h} = \ell_T$ | |
| Holt–Winters (add.) | level, slope, season each smoothed ($\alpha, \beta, \gamma$); $\hat y_{T+h} = \ell_T + h\,b_T + s_{T+h-m}$; damped: $(\phi + \dots + \phi^h)b_T$ | |
| ARIMA($p,d,q$)($P,D,Q$)$_m$ | difference $d$ (and seasonal $D$) times; $y'_t = c + \sum\phi_j y'_{t-j} + \varepsilon_t + \sum\theta_j\varepsilon_{t-j}$; MLE | |

## Defaults and rules of thumb
- Recommenders: baselines = bias model (ratings) and "most watched" (ranking); $k$ = 20–100 factors; $\lambda$ and epochs on a time-ordered validation block.
- Implicit data: 4–10 sampled negatives per positive; judge by recall@k / NDCG@k, never RMSE.
- Two stages: retriever recall@$N$ (100–1,000) is the ceiling; reranker needs information the retriever lacks (recency, context, pair features).
- Forecasting: seasonal naive first; every feature ≥ horizon old (`shift` before `rolling`); walk-forward, test size = horizon, refit each origin; report every fold.
- Classical (ETS/SARIMA) for short, smooth, single series; boosting for many series and known non-linear drivers; difference the target for trees.

## Pitfalls
- Random split of interactions or of a time series (lab: −0.06 to −0.09 RMSE; shuffled CV a third too optimistic).
- Missing ratings treated as 0 (zero-filled SVD RMSE 2.54); means computed over zero-filled rows.
- Best RMSE ≠ best top-10 (explicit MF recall@10 0.019 vs popularity 0.067).
- IDCG built from retrieved candidates only (NDCG inflated 42%); $\log_2 j$ instead of $\log_2(j + 1)$.
- Centred windows, off-by-one shifts, interpolation or scalers over the whole series; observed weather used for training, forecasts at serving time.
- Trees on a trending level flatten at the training maximum; comparing models that saw different information.
- `[RAI]` Feedback loops starve new items and sellers: track coverage and exposure by group.

## Interview one-liners
- **Collaborative filtering:** recommend from the behaviour of similar users or items, no content needed.
- **Matrix factorization:** learn user and item vectors whose dot products fit the observed interactions only.
- **Negative sampling:** contrast positives with random unseen items, freshly drawn, because unseen ≠ disliked.
- **NDCG:** position-discounted gain normalized by the ideal list; handles graded relevance.
- **Retrieve-then-rank:** cheap high-recall candidates, then an expensive precise ranker.
- **Walk-forward validation:** train on the past, forecast the next horizon, roll forward, repeat.
- **Seasonal naive:** "same period last cycle", the bar every forecast must beat.
- **SES / Holt–Winters / ARIMA:** exponentially weighted level (+ slope + season) / linear model of differenced values and past errors.
