# Week 05 cheat sheet: A5 Probability

## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Expectation | $\mathbb{E}[X] = \sum x\,p(x)$ (or $\int x\,p(x)\,dx$); $\mathbb{E}[aX + b] = a\mathbb{E}[X] + b$; $\mathbb{E}[X + Y] = \mathbb{E}[X] + \mathbb{E}[Y]$ | scalar |
| Variance | $\operatorname{Var}[X] = \mathbb{E}[X^2] - \mathbb{E}[X]^2$; $\operatorname{Var}[aX + b] = a^2\operatorname{Var}[X]$ | scalar |
| Covariance | $\operatorname{Cov}[X, Y] = \mathbb{E}[XY] - \mathbb{E}[X]\mathbb{E}[Y]$; $\rho = \operatorname{Cov}/(\sigma_X\sigma_Y)$ | scalar |
| Sum | $\operatorname{Var}[X \pm Y] = \operatorname{Var}[X] + \operatorname{Var}[Y] \pm 2\operatorname{Cov}[X, Y]$; independent ⇒ Cov = 0 (not ⇐) | |
| Estimators | $\bar{x} = \frac1n\sum x_i$, $s^2 = \frac{1}{n-1}\sum(x_i - \bar{x})^2$; $\mathrm{SE}(\bar{x}) = \sigma/\sqrt{n}$ | |
| Bernoulli / binomial | mean $p$, var $p(1-p)$ / $\binom{n}{k}p^k(1-p)^{n-k}$, mean $np$, var $np(1-p)$ | |
| Poisson($\lambda$) | $e^{-\lambda}\lambda^k/k!$; mean = var = $\lambda$; $P(k) = P(k-1)\cdot\lambda/k$ | |
| Uniform($a$, $b$) | density $\frac{1}{b-a}$; mean $\frac{a+b}{2}$, var $\frac{(b-a)^2}{12}$ | |
| Gaussian | $\frac{1}{\sqrt{2\pi\sigma^2}}e^{-(x-\mu)^2/2\sigma^2}$; within 1/2/3σ: 68.3/95.4/99.7% | |
| Multivariate | $\mathbf{x} = \boldsymbol{\mu} + \mathbf{L}\mathbf{z}$, $\mathbf{L}\mathbf{L}^\top = \boldsymbol{\Sigma}$ ⇒ $\operatorname{Cov}[\mathbf{x}] = \boldsymbol{\Sigma}$ | `(d,)`, `(d, d)` |
| Box–Muller | $r = \sqrt{-2\log u_1}$, $\theta = 2\pi u_2$, $z = (r\cos\theta, r\sin\theta)$ | |
| Bayes | $P(A \mid B) = \frac{P(B \mid A)P(A)}{P(B \mid A)P(A) + P(B \mid \bar{A})P(\bar{A})}$ | |
| Odds form | posterior odds = $\mathrm{LR}_+ \times$ prior odds; $\mathrm{LR}_+ = \frac{\text{sens}}{1 - \text{spec}}$; $P = \frac{o}{1+o}$ | |
| CLT | $\bar{X}_n \approx \mathcal{N}(\mu, \sigma^2/n)$; 95% bar $\bar{x} \pm 1.96\,s/\sqrt{n}$; $n = (1.96\sigma/E)^2$ | |
| Monte Carlo | $\mathbb{E}[g(X)] \approx \frac1n\sum g(x_i)$; $\int_a^b f = (b-a)\mathbb{E}[f(U)]$; error $\propto 1/\sqrt{n}$ | |
| NLL | $-\sum_i\log p(x_i \mid \boldsymbol{\theta})$; MLE = argmin | |
| Gaussian MLE | $\hat{\mu} = \bar{x}$, $\hat{\sigma}^2 = \frac1n\sum(x_i - \bar{x})^2$ (÷ n) | |
| Losses as NLL | Gaussian → MSE; Bernoulli → log-loss $-[y\log p + (1-y)\log(1-p)]$; Laplace → MAE | |
| MAP = ridge | $\lVert\mathbf{y} - \mathbf{X}\mathbf{w}\rVert^2 + \lambda\lVert\mathbf{w}\rVert^2$, $\lambda = \sigma^2/\tau^2$; $(\mathbf{X}^\top\mathbf{X} + \lambda\mathbf{D})^{-1}\mathbf{X}^\top\mathbf{y}$ | `(d,)` |

rng = np.random.default_rng(SEED); x.var(ddof=1); np.cov(X, rowvar=False)   # (n, d) -> (d, d)
(rng.random(n) < p)                                  # Bernoulli; categorical: inverse CDF below
np.searchsorted(np.cumsum(probs), rng.random(n), side="right")
mu + rng.standard_normal((n, d)) @ np.linalg.cholesky(Sigma).T              # (n, d), cov Sigma
stats.binom(n, p).pmf(k); stats.poisson(lam).pmf(k); stats.norm(mu, sd).cdf(x)  # scale = sd
(sick & pos).sum() / pos.sum()                       # P(sick | pos) by counting = precision
est, se = fx.mean(), fx.std(ddof=1) / np.sqrt(n)     # Monte Carlo with error bar
stats.norm.fit(x)                                    # Gaussian MLE (sd divides by n)
Ridge(alpha=sigma2 / tau2); LogisticRegression(C=tau2)   # MAP; larger C = weaker prior
log_loss(y, np.clip(p, 1e-15, 1 - 1e-15))

## Defaults and rules of thumb
- Pass `ddof` explicitly (NumPy 0, pandas 1); `np.cov` wants `rowvar=False` for `(n, d)` data.
- Check a simulator against exact values; check samplers on the whole shape (largest CDF gap).
- Reason with 10,000 imaginary people; quote precision at the production base rate.
- Report every average as estimate ± 1.96 SE (n = …); 100× data buys one digit.
- Standardize features before a Gaussian prior; never penalize the intercept.

## Pitfalls
- Zero correlation read as independence; adding variances of correlated parts.
- `Z @ L` instead of `Z @ L.T`: covariance $\mathbf{L}^\top\mathbf{L}$, no error raised.
- $P(+ \mid D)$ read as $P(D \mid +)$; precision from a balanced test set; multiplying correlated evidence.
- "CLT makes the data Gaussian" (it is the mean); $n \ge 30$ with skew or heavy tails; correlated samples.
- `log(0)` in log-loss; MSE with outliers or growing noise; separable data → MLE weights diverge.

## Interview one-liners
- **Expectation:** the probability-weighted average; linear, always.
- **Base rate:** a rare condition makes most positives false, even for an accurate test.
- **CLT:** averages of many independent draws are approximately Gaussian with sd $\sigma/\sqrt{n}$.
- **MLE:** parameters that make the data most probable; MSE = Gaussian MLE, log-loss = Bernoulli MLE.
- **MAP:** MLE plus a prior; a Gaussian prior is L2 regularization with $\lambda = \sigma^2/\tau^2$.
