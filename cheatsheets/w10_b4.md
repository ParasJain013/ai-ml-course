## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Confusion ratios | precision $\frac{TP}{TP+FP}$; recall = TPR $\frac{TP}{P}$; FPR $\frac{FP}{N}$; $F_1 = \frac{2TP}{2TP+FP+FN}$ | |
| ROC-AUC | trapezoid under (FPR, TPR) $= P(s_+ > s_-)$, ties ½; rank form $\frac{\sum_{+}\text{rank} - P(P+1)/2}{PN}$ | |
| Average precision | $\sum_k (R_k - R_{k-1})P_k$ = mean precision at each positive; baseline = prevalence $\pi$ | |
| Calibration | reliability: per bin, mean $\hat p$ vs observed rate; Brier $\frac1n\sum(\hat p - y)^2$, baseline $\pi(1-\pi)$ | |
| Regression | MAE $\frac1n\sum\lvert e\rvert$ (median); RMSE $\sqrt{\frac1n\sum e^2}$ (mean); MAPE $\frac1n\sum\frac{\lvert e\rvert}{\lvert y\rvert}$; WAPE $\frac{\sum\lvert e\rvert}{\sum\lvert y\rvert}$; $R^2 = 1 - \frac{SSE}{SST}$ | `(n,)` |
| Pinball loss | $\max(\tau e, (\tau - 1)e)$, $e = y - \hat y$; optimum = $\tau$-quantile; $\tau = \frac{c_{under}}{c_{under}+c_{over}}$ | |
| Cost threshold | flag if $p > \frac{c_{FP}}{c_{FP}+c_{FN}}$ (calibrated $p$); else minimize $\frac1n(c_{FP}FP + c_{FN}FN)$ over $t$ | |
| Time-series split | $m = \lfloor n/(k+1)\rfloor$; fold $f$ tests $[n - km + fm, n - km + (f+1)m)$, trains on all before | |
| Selection bias | best of $B$ noisy scores ≈ truth $- c_B\sigma$; $c_{20} \approx 1.87$ | |
| Class weight $w$ | weighted model's odds $= w \times$ true odds; prior correction: odds $\times 1/w$ (or $\times\beta$ after undersampling) | |
| Weight = threshold | weight $w$ + cut 0.5 ⇔ cut $1/(1+w)$ on calibrated $p$ ⇔ cost ratio $c_{FN}/c_{FP} = w$ | |
| Bias–variance | $\mathbb{E}(y - \hat f)^2 = \sigma^2 + (f - \bar f)^2 + \mathbb{E}(\hat f - \bar f)^2$ | |
| Group rates | $\text{SR}_a = \text{TPR}_a\pi_a + \text{FPR}_a(1 - \pi_a)$; DP diff, EOpp diff (TPR), EOdds = max(TPR gap, FPR gap) | |

## Defaults and rules of thumb
- Splitter from how data was generated: stratified (rare class), group (repeated entities), time-ordered (forecasting).
- Report baselines: majority class, prevalence (AP), $\pi(1 - \pi)$ (Brier), mean/median (regression).
- Threshold from costs or capacity on out-of-fold predictions; test set touched once, with a bootstrap CI.
- Imbalance: right metric + threshold first; weights/resampling only for a measured gain, then recalibrate.
- Learning curve flat and high → capacity; big shrinking gap → data/regularization/averaging.
- Fairness: per-group sizes, base rates, SR, TPR, FPR with CIs; choose the gap with stakeholders; model card §6.10.

## Pitfalls
- Accuracy / ROC-AUC on rare positives; F1 at 0.5 by habit; thresholds or calibration fitted on the reported rows.
- MAPE with zeros (sklearn returns ~1e15); $R^2$ compared across datasets.
- Shuffled k-fold with customers or time; resampling or scaling before the split.
- Reporting the best CV score of a large search as expected performance.
- Rebalanced probabilities shown as risks; "balanced" weights = an unstated cost ratio.
- Dropping the sensitive column and calling it fair (proxies); acting on gaps from tiny groups.

## Interview one-liners
- **PR vs ROC:** FPR hides false alarms when negatives are plentiful; precision counts them.
- **Calibration:** $P(y = 1 \mid \hat p = q) = q$; fix with Platt/isotonic on held-out rows; ranking unchanged.
- **Nested CV:** inner loop tunes, outer loop scores the whole tuning procedure on unseen rows.
- **Class weights:** multiply odds by $w$; equivalent to a lower threshold; break calibration.
- **Bias–variance:** systematic miss vs scatter across training sets; curves tell you which dominates.
- **Fairness impossibility:** different base rates ⇒ no useful classifier has both equal selection and equalized odds.
