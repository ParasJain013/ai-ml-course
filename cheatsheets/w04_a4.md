# Week 04 cheat sheet: A4 Calculus & optimization

## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Forward difference | $\frac{f(x + h) - f(x)}{h}$, error $\approx \frac{h}{2}f''$ | best $h \approx \sqrt{\varepsilon} \approx 10^{-8}$ |
| Central difference | $\frac{f(x + h) - f(x - h)}{2h}$, error $\approx \frac{h^2}{6}f'''$ | best $h \approx \varepsilon^{1/3} \approx 10^{-5}$ |
| Rounding error | $\approx \varepsilon\lvert f\rvert/h$; $\varepsilon = 2.2 \times 10^{-16}$ (f64), $1.2 \times 10^{-7}$ (f32) | U-shaped total |
| Gradient | $\nabla f = (\partial f/\partial x_1, \dots)$; $f(\mathbf{x} + \boldsymbol{\delta}) \approx f + \nabla f\cdot\boldsymbol{\delta}$ | same shape as $\mathbf{x}$ |
| Jacobian | $J_{ij} = \partial F_i/\partial x_j$; $\mathbf{A}\mathbf{x} \to \mathbf{A}$; elementwise $g \to \operatorname{diag}(g')$ | `(m, p)` |
| Four results | $\nabla\mathbf{a}^\top\mathbf{x} = \mathbf{a}$; $\nabla\mathbf{x}^\top\mathbf{M}\mathbf{x} = (\mathbf{M} + \mathbf{M}^\top)\mathbf{x}$; $\nabla\lVert\mathbf{A}\mathbf{x} - \mathbf{b}\rVert^2 = 2\mathbf{A}^\top(\mathbf{A}\mathbf{x} - \mathbf{b})$ | |
| MSE gradient | $\frac{2}{n}\mathbf{X}^\top(\mathbf{X}\mathbf{w} - \mathbf{y})$; matrix: $\frac{2}{n}\mathbf{X}^\top\mathbf{R}$; bias: $\frac{2}{n}\sum_i\mathbf{R}_{i,:}$ | `(d,)`, `(d, k)`, `(k,)` |
| MSE Hessian | $\mathbf{H} = \frac{2}{n}\mathbf{X}^\top\mathbf{X}$; gradient $= 0$ ⇔ normal equations | `(d, d)` |
| Chain rule | $\frac{df}{dx} = \sum_{\text{paths}}\prod(\text{local derivatives})$; VJP $\bar{\mathbf{u}} = \mathbf{J}^\top\bar{\mathbf{v}}$ | $\bar{\mathbf{u}}$ like $\mathbf{u}$ |
| Local derivatives | add 1; multiply → other input; $u^2 \to 2u$; $\sigma \to \sigma(1 - \sigma)$; $\tanh \to 1 - \tanh^2$ | |
| GD | $\mathbf{w} \leftarrow \mathbf{w} - \eta\nabla\mathcal{L}$; per eigen-direction error $\times(1 - \eta\lambda_j)$ | |
| Stability, speed | $\eta < 2/\lambda_{\max}$; steps $\sim \kappa = \lambda_{\max}/\lambda_{\min}$ per factor $e$; best fixed $\eta = \frac{2}{\lambda_{\min} + \lambda_{\max}}$ | |
| Convex | $f(t\mathbf{x} + (1 - t)\mathbf{y}) \le tf(\mathbf{x}) + (1 - t)f(\mathbf{y})$ ⇔ Hessian PSD everywhere | |
| Lagrange | $\nabla f = \lambda\nabla g$, $g = c$; $F = f - \lambda(g - c)$; $\lambda = df^\star/dc$ | |
| KKT ($g \le c$) | $\nabla f + \mu\nabla g = \mathbf{0}$, $\mu \ge 0$, $g \le c$, $\mu(g - c) = 0$ | |

## Defaults and rules of thumb
- Gradient check: rel. error < 1e-7 pass, > 1e-4 bug; random points, tiny sizes, float64, no dropout.
- Learning rate: log grid, largest with a smoothly falling curve; plot loss on a log scale.
- Standardize features; shuffle every epoch; decay the rate for the last part of training.
- Convex losses (linear, ridge, logistic, SVM): one run suffices. Neural nets: ≥ 3 seeds.

## Pitfalls
- `y` of shape `(n, 1)` → `(n, n)` residual; `=` instead of `+=` at fan-outs; $2\mathbf{M}\mathbf{x}$ for non-symmetric $\mathbf{M}$.
- $h$ too small (rounding), float32, kinks (ReLU at 0), randomness inside $f$.
- $\eta$ a few % above $2/\lambda_{\max}$ diverges exponentially; unscaled features shrink $2/\lambda_{\max}$.
- SGD with constant $\eta$ hovers; unshuffled data gives sawtooth loss.
- `success=True` = stationary point, not global minimum. SciPy `ineq` means `fun(v) >= 0`.

## Interview one-liners
- **Gradient:** vector of partials, steepest ascent, same shape as the parameter.
- **Backprop:** chain rule in reverse over the graph; one backward pass for all parameters; costs activation memory.
- **Learning rate:** too low crawls, above $2/\lambda_{\max}$ diverges; feature scale sets the safe range.
- **Convexity:** every local minimum is global; NN losses lack it, so seeds matter.
- **Lagrange multiplier:** shadow price of a constraint, $df^\star/dc$; support vectors have $\mu > 0$.
