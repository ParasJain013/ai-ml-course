## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Derivative | $f(x + h) \approx f(x) + f'(x)h$; $f' = \lim_{h\to 0}\frac{f(x+h) - f(x)}{h}$ | scalar |
| Rules | $(x^k)' = kx^{k-1}$, $(e^x)' = e^x$, $(\log x)' = 1/x$, $(fg)' = f'g + fg'$ | |
| Forward / central difference | $\frac{f(x+h) - f(x)}{h}$, error $\approx\frac{f''}{2}h$; $\frac{f(x+h) - f(x-h)}{2h}$, error $\approx\frac{f'''}{6}h^2$ | |
| Rounding error | $\approx \varepsilon\lvert f\rvert/h$, $\varepsilon = 2.2\times10^{-16}$ (float64), $1.2\times10^{-7}$ (float32) | |
| Gradient | $\nabla f = (\partial f/\partial x_1, \dots)$; $f(\mathbf{x} + \boldsymbol{\delta}) \approx f + \nabla f\cdot\boldsymbol{\delta}$ | same as $\mathbf{x}$ |
| Jacobian | $J_{ij} = \partial f_i/\partial x_j$; $\mathbf{f}(\mathbf{x} + \boldsymbol{\delta}) \approx \mathbf{f} + \mathbf{J}\boldsymbol{\delta}$ | `(m, n)` |
| Patterns | $\nabla\mathbf{a}^\top\mathbf{w} = \mathbf{a}$; $\nabla\mathbf{x}^\top\mathbf{M}\mathbf{x} = (\mathbf{M} + \mathbf{M}^\top)\mathbf{x}$; $\nabla\lVert\mathbf{A}\mathbf{x} - \mathbf{b}\rVert^2 = 2\mathbf{A}^\top(\mathbf{A}\mathbf{x} - \mathbf{b})$ | |
| MSE gradient | $\nabla_{\mathbf{w}}\frac1n\lVert\mathbf{X}\mathbf{w} - \mathbf{y}\rVert^2 = \frac{2}{n}\mathbf{X}^\top\mathbf{r}$; bias: $\frac{2}{n}\sum r_i$ | `(d,)` |
| Linear layer | $\mathbf{Z} = \mathbf{X}\mathbf{W}$: $\bar{\mathbf{W}} = \mathbf{X}^\top\bar{\mathbf{Z}}$, $\bar{\mathbf{X}} = \bar{\mathbf{Z}}\mathbf{W}^\top$; bias: sum $\bar{\mathbf{Z}}$ over rows | `(d_in, d_out)` |
| Chain rule | $\frac{dy}{dx} = \frac{dy}{du}\frac{du}{dx}$; several paths add; $\mathbf{J}_{f\circ g} = \mathbf{J}_f\mathbf{J}_g$ | |
| Local derivatives | add copies; multiply swaps; $\sigma' = \sigma(1 - \sigma)$; $\tanh' = 1 - \tanh^2$; $\log' = 1/u$ | |
| Log loss + sigmoid | $\partial\mathcal{L}/\partial z = p - y$ | |
| Gradient descent | $\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \eta\nabla\mathcal{L}$; MSE Hessian $\mathbf{H} = \frac{2}{n}\mathbf{X}^\top\mathbf{X}$ | `(d, d)` |
| Convergence | error along $\mathbf{q}_j$ $\times(1 - \eta\lambda_j)$ per step; stable iff $\eta < 2/\lambda_{\max}$ | |
| Best fixed rate | $\eta^\star = \frac{2}{\lambda_{\min} + \lambda_{\max}}$, factor $\frac{\kappa - 1}{\kappa + 1}$; steps $\approx\frac{\kappa}{2}\ln F$ | $\kappa = \lambda_{\max}/\lambda_{\min}$ |
| Convex | $f(t\mathbf{x} + (1-t)\mathbf{y}) \le tf(\mathbf{x}) + (1-t)f(\mathbf{y})$; $f'' \ge 0$ / Hessian PSD | |
| Lagrange | $\min f$ s.t. $h = c$: $\nabla f = \lambda\nabla h$, $h = c$; $\lambda = df^\star/dc$ | |
| KKT | $\min f$ s.t. $g \le 0$: $\nabla f + \mu\nabla g = 0$, $\mu \ge 0$, $\mu g = 0$ | |
| Constraint = penalty | $\min\mathcal{L}$ s.t. $\lVert\mathbf{w}\rVert^2 \le r^2$ ⇔ $\min\mathcal{L} + \mu\lVert\mathbf{w}\rVert^2$ (ridge) | |

```python
(f(x + h) - f(x - h)) / (2 * h)                     # central difference, h = 1e-6, float64
rel = np.linalg.norm(a - b) / (np.linalg.norm(a) + np.linalg.norm(b))   # < 1e-6 passes
grad = 2 / n * X.T @ (X @ w - y)                    # MSE gradient, (d,); assert r.shape == (n,)
dW, db = X.T @ dZ, dZ.sum(axis=0)                   # linear layer backward
dz = dp * p * (1 - p)                               # through a sigmoid (elementwise)
lam = np.linalg.eigvalsh(2 / n * X.T @ X); lr = 2 / (lam[0] + lam[-1])
w -= lr * grad                                      # GD step; check np.isfinite(loss)
idx = rng.permutation(n)[s:s + B]                   # mini-batch; reshuffle every epoch
optimize.check_grad(f, grad_f, x0)                  # absolute norm of the difference
optimize.minimize(f, x0, jac=g, method="BFGS")      # local, even on non-convex f

```

## Defaults and rules of thumb
- Check every hand-written gradient: float64, central differences, random points, unequal dimensions.
- Standardize features before GD (fit the scaler on training data only).
- Try learning rates on a log grid; keep the largest that decreases the loss smoothly.
- Stop on $\lVert\nabla\mathcal{L}\rVert$ or loss change, with a step cap that raises.
- SGD: batch 32–256, shuffle each epoch, decay the learning rate.

## Pitfalls
- `h = 1e-12`, or float32 checks: rounding swamps the derivative.
- `y` shaped `(n, 1)` against `X @ w` shaped `(n,)` broadcasts to `(n, n)` silently.
- $2\mathbf{M}\mathbf{x}$ for non-symmetric $\mathbf{M}$; a missing 2 or $1/n$ (constant relative error).
- Fan-out: `=` instead of `+=` in a backward pass; bias gradients not summed over rows.
- $\eta > 2/\lambda_{\max}$ diverges; constant-rate SGD never settles.
- $\nabla f = \mathbf{0}$ or the Lagrange conditions also hold at maxima and saddles; BFGS is still local.

## Interview one-liners
- **Gradient:** direction of steepest increase; same shape as the parameters.
- **Backprop:** reverse-mode chain rule; one backward pass gives every parameter's gradient; costs memory.
- **Learning rate:** step size; stable below $2/\lambda_{\max}$; speed set by the condition number.
- **Convexity:** chords above the graph, so local minimum = global minimum.
- **Lagrange multiplier:** shadow price of a constraint; L2 penalty = norm constraint.
