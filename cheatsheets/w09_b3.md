## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Gini, entropy (bits) | $G = 1 - \sum_k p_k^2$; $H = -\sum_k p_k\log_2 p_k$; 2 classes: $G = 2p(1-p) \le 0.5$, $H \le 1$ | scalar |
| Split cost, gain | $I_{\text{split}} = \frac{m_L}{m}I(S_L) + \frac{m_R}{m}I(S_R)$; gain $= I(S) - I_{\text{split}}$; thresholds = midpoints | |
| Regression tree | leaf = mean; impurity = variance; SSE $= \sum y^2 - (\sum y)^2/m$ (running sums) | |
| Bootstrap | $P(\text{out of bag}) = (1 - 1/n)^n \to 1/e = 0.368$; each tree sees 63.2% of distinct rows | |
| Averaging trees | $\operatorname{Var}[\bar T] = \rho\sigma^2 + (1-\rho)\sigma^2/B$; bias unchanged | |
| Majority of 3 | $3p^2(1-p) + p^3$ (independent): 0.784 for $p = 0.7$ | |
| Boosting | $F_M = F_0 + \eta\sum_m f_m$; $f_m$ fits $r_i = -g_i$; squared error: $r = y - F$; log-loss: $r = y - p$ | `(n,)` |
| Newton leaf (log-loss) | $w_j = \sum_{i \in I_j} r_i / \sum_{i \in I_j} p_i(1-p_i)$; $F_0 = \log\frac{\bar y}{1 - \bar y}$ | |
| XGBoost objective | $\Omega = \gamma T + \frac12\lambda\lVert\mathbf{w}\rVert^2$; $w_j^* = -G_j/(H_j + \lambda)$; score $-\frac12\sum_j G_j^2/(H_j + \lambda) + \gamma T$ | |
| XGBoost gain | $\frac12\big[\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\big] - \gamma$; squared error: $g = F - y$, $h = 1$ | |
| Permutation importance | $I_j = s(f, \mathbf{X}, \mathbf{y}) - \frac1R\sum_r s(f, \mathbf{X}^{(\pi_r, j)}, \mathbf{y})$ on held-out rows | `(d,)` |
| PD, ICE | $\text{ICE}_i(u) = f(u, \mathbf{x}_{i,-j})$; $\text{PD}_j(u) = \frac1m\sum_i \text{ICE}_i(u)$ | |
| Shapley value | $\phi_j = \sum_{S \subseteq N \setminus j}\frac{\lvert S\rvert!(d - \lvert S\rvert - 1)!}{d!}[v(S \cup j) - v(S)]$; $d = 3$ weights $\frac13, \frac16, \frac16, \frac13$; $\sum\phi_j = f(\mathbf{x}) - v(\varnothing)$ | |
| Coalition value | $v(S) = \frac{1}{\lvert\mathcal{B}\rvert}\sum_{\mathbf{b}} f(\mathbf{x}_S, \mathbf{b}_{\bar S})$ (interventional) | |

## Defaults and rules of thumb
- Trees need no scaling and handle interactions; one tree for reading (depth 2–4), ensembles for accuracy.
- Forest: deep trees, `max_features` "sqrt" (classification) or ~0.33 (regression; the default 1.0 is plain bagging), 200–500 trees.
- Boosting: $\eta$ 0.03–0.1 + early stopping on a slice that is *not* the reporting set; depth 4–8 or `num_leaves` 15–127.
- Halving $\eta$ ≈ doubling the trees. Fix `random_state`: ties between equally good splits are broken randomly.
- Report importance as permutation (held-out) or mean |SHAP|; group correlated features.

## Pitfalls
- Unlimited trees: training accuracy 1.0, pure leaves, 0/1 probabilities, exploding log-loss.
- OOB score on grouped or time-ordered rows (leaks like random k-fold); `forest.score(X_train)` ≈ 1.0 means nothing.
- Learning rate 1.0: the validation curve bottoms out in a handful of rounds and rises; early stopping on the test set.
- Trees cannot extrapolate past the training targets (trends, prices that keep rising).
- MDI ranks noise above real 0/1 features; shuffling one of two dependent features creates impossible rows.
- SHAP/PD/permutation explain the model, not causes; the SHAP base value depends on the background.

## Interview one-liners
- **CART:** greedy, exhaustive search over features × midpoints for the lowest weighted child impurity.
- **Random forest:** bagging + random features per split → less correlated trees → lower variance floor $\rho\sigma^2$.
- **Gradient boosting:** gradient descent in function space: shallow trees fitted to negative gradients, shrunk by $\eta$.
- **XGBoost:** regularized objective + second-order leaf values $-G/(H+\lambda)$ + sparsity-aware splits + system tricks.
- **SHAP:** Shapley values over features; contributions add up to prediction − base value; TreeSHAP is exact and fast.
