## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Perceptron rule | if $y(\mathbf{w}^\top\mathbf{x} + b) \le 0$: $\mathbf{w} \mathrel{+}= \eta y\mathbf{x}$, $b \mathrel{+}= \eta y$ ($y = \pm1$) | $\mathbf{w}$ `(d,)` |
| Dense layer | $\mathbf{H} = f(\mathbf{X}\mathbf{W} + \mathbf{b})$; no activation on the last layer (logits) | `(n, d_in) @ (d_in, d_out)` |
| Linear collapse | $(\mathbf{X}\mathbf{W}_1 + \mathbf{b}_1)\mathbf{W}_2 + \mathbf{b}_2 = \mathbf{X}(\mathbf{W}_1\mathbf{W}_2) + (\mathbf{b}_1\mathbf{W}_2 + \mathbf{b}_2)$ | one layer |
| Activations' $f'$ | $\sigma' = \sigma(1 - \sigma) \le 0.25$; $\tanh' = 1 - \tanh^2$; ReLU$' = \mathbb{1}[z > 0]$ | elementwise |
| Dense backward | $\mathbf{G}_{\mathbf{W}} = \mathbf{X}^\top\boldsymbol{\Delta}$; $\mathbf{G}_{\mathbf{b}} = \sum_i\boldsymbol{\delta}_i$; $\mathbf{G}_{\mathbf{X}} = \boldsymbol{\Delta}\mathbf{W}^\top$ | `(d_in, d_out)`, `(d_out,)`, `(n, d_in)` |
| Activation backward | $\mathbf{G}_{\mathbf{Z}} = \mathbf{G}_{\mathbf{H}} \odot f'(\mathbf{Z})$ | `(n, d)` |
| Autograd node rule | $\mathbf{G}_{\text{input}} \mathrel{+}= $ local derivative applied to $\mathbf{G}_{\text{out}}$; visit in reverse topological order | |
| Broadcast backward | sum over added leading axes and stretched size-1 axes ("unbroadcast") | grad shape = input shape |
| Sum ↔ copy | backward of `sum` copies; backward of a broadcast (copy) sums | |
| Softmax | $p_k = e^{z_k - m}/\sum_j e^{z_j - m}$, $m = \max_j z_j$ | `(n, K)` |
| Log-sum-exp | $\operatorname{LSE}(\mathbf{z}) = m + \log\sum_k e^{z_k - m}$, between $m$ and $m + \log K$ | `(n,)` |
| Cross-entropy | $\ell = \operatorname{LSE}(\mathbf{z}) - z_y$; gradient $\mathbf{p} - \mathbf{y}$; batch mean $(\mathbf{P} - \mathbf{Y})/n$ | `(n, K)` |
| Softmax Jacobian | $\partial p_k/\partial z_j = p_k(\delta_{kj} - p_j)$; VJP $\mathbf{p} \odot (\mathbf{g} - \mathbf{g}\cdot\mathbf{p})$ | `(K, K)` never formed |
| 2 classes | logits $(0, z)$: $p_2 = \sigma(z)$, $\ell = \log(1 + e^z) - yz$ (B2.1) | |

## Code
```python
Z1 = X @ W1 + b1; H = np.maximum(Z1, 0); Z2 = H @ W2 + b2           # forward, cache Z1, H
D2 = (softmax(Z2) - Y) / n                                           # delta of softmax + CE
dW2, db2 = H.T @ D2, D2.sum(axis=0); D1 = (D2 @ W2.T) * (Z1 > 0)    # backward
dW1, db1 = X.T @ D1, D1.sum(axis=0)
self.grad += unbroadcast(out.grad, self.shape)                      # every + and * in a Tensor engine
lse = m + np.log(np.exp(z - m[..., None]).sum(-1)); log_p = z - lse[..., None]
F.cross_entropy(logits, y)            # logits + int targets; never softmax first
```

## Defaults and rules of thumb
- ReLU in hidden layers, no activation on the output; 1–3 hidden layers of 64–512 for tabular or embedding inputs.
- Gradient-check every new op: float64, $h = 10^{-6}$, relative error $< 10^{-6}$, non-square shapes, random biases, random output weights.
- Zero gradients before every `backward()`; assert `grad.shape == param.shape`.
- Compute losses from logits: `log_softmax`, `cross_entropy`, `BCEWithLogitsLoss`, `logaddexp`.
- Overflow: `exp` above 709.78 (float64) / 88.72 (float32); naive CE breaks at logits ~52 (float32).

## Pitfalls
- No activation between layers: a deep linear model. Activation on the logits: classes that can never win.
- `=` instead of `+=` in backward: wrong gradient for any value used twice ($y = x^2$ gives $x$, not $2x$).
- `delta.T @ X` instead of `X.T @ delta`: same shape on square layers, wrong values.
- Missing $\frac1n$, or bias gradient shaped `(1, k)` broadcasting silently.
- Softmax before `CrossEntropyLoss` (double softmax); `log(p + eps)` hides `NaN` and kills the worst examples' gradient.
- All-equal initial weights: hidden units stay identical (symmetry). Gradient checks at a kink (ReLU at 0, tied max) fail falsely.

## Interview one-liners
- **Perceptron:** a linear unit with a step; converges iff the data is linearly separable.
- **MLP:** stacked dense layers with non-linear activations; a ReLU MLP is piecewise linear.
- **Universal approximation:** one hidden layer can approximate any continuous function given enough units; says nothing about how many or about learning.
- **Backpropagation:** the chain rule applied backwards; all gradients for ~2 forward passes of compute, at the cost of caching activations.
- **Delta:** $\partial\mathcal{L}/\partial\mathbf{Z}$; every gradient of a layer is one matrix product away from it.
- **Autograd:** record a graph in the forward pass, run local backward rules in reverse topological order, accumulate with `+=`.
- **Log-sum-exp trick:** subtract the max before exponentiating; exact because softmax is shift-invariant.
- **Softmax + cross-entropy:** fused for stability; gradient $\mathbf{p} - \mathbf{y}$.
