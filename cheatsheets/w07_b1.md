## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Empirical risk | $\hat R(f) = \frac1n\sum_i \ell(f(\mathbf{x}_i), y_i)$ on training rows; generalization gap = val error − train error | scalar |
| $R^2$ | $1 - \sum(y_i - \hat y_i)^2/\sum(y_i - \bar y)^2$; mean baseline ≈ 0 (can be < 0 on val) | scalar |
| Test-reuse inflation | best of $k$ equal models ≈ $p + \mathbb{E}[\max_k]\,\mathrm{SE}$, $\mathrm{SE} = \sqrt{p(1-p)/n}$; $\mathbb{E}[\max]$ = 1.54, 2.51, 3.24 for $k$ = 10, 100, 1000 | |
| Mean imputation | $\operatorname{Var}[\tilde{\mathbf{x}}] = (1 - \pi)\,\hat\sigma^2_{\text{obs}}$, $\pi$ = share missing; correlations shrink too | `(n,)` |
| z-score ceiling | with $\sigma$ dividing by $n$, $\lvert z\rvert \le \sqrt{n - 1}$: a 3σ rule cannot fire when $n \le 10$ | |
| Standardize | $z = (x - \mu_{\text{train}})/\sigma_{\text{train}}$; min–max $(x - \min)/(\max - \min)$ (train stats) | `(n, d)` |
| Cyclic encoding | $(\sin\theta, \cos\theta)$, $\theta = 2\pi(v - v_0)/P$, $v_0$ the first value; neighbours $2\sin(\pi/P)$ apart | `(n,)` → `(n, 2)` |
| One-hot rank | $K$ dummies + intercept: columns dependent (rank $K$), so $\mathbf{X}^\top\mathbf{X}$ singular → drop one or regularize | |
| k-anonymity | every combination of quasi-identifiers shared by ≥ $k$ rows | |
| Pseudonym | $\operatorname{HMAC\text{-}SHA256}(\text{key}, \text{id})$, key in a secret store; still personal data | |
| ROC-AUC | $P(\text{score}_+ > \text{score}_-)$, ties ½; $U = R_+ - n_+(n_+ + 1)/2$, AUC $= U/(n_+n_-)$ | scalar |
| Least squares | $\mathbf{A} = [\mathbf{1}, \mathbf{X}]$; $\mathbf{A}^\top\mathbf{A}\boldsymbol\theta = \mathbf{A}^\top\mathbf{y}$; residuals ⟂ every column, sum to 0 | `(d+1,)` |
| One feature | $w = \sum dx\,dy/\sum dx^2$, $b = \bar y - w\bar x$ | |
| MSE gradient / Hessian | $\nabla = \frac2n\mathbf{A}^\top(\mathbf{A}\boldsymbol\theta - \mathbf{y})$; $\mathbf{H} = \frac2n\mathbf{A}^\top\mathbf{A}$ | `(d+1,)`, `(d+1, d+1)` |
| GD rate | stable iff $\eta < 2/\lambda_{\max}$; best $\eta = 2/(\lambda_{\min} + \lambda_{\max})$; error × $(\kappa - 1)/(\kappa + 1)$ per step | |
| Back to raw units | $w_j = w_{z,j}/\sigma_j$, $b = b_z - \sum_j w_j\mu_j$ | |

## Defaults and rules of thumb
- Frame first: decision, prediction time, label horizon, metric, baseline; build every row "as of" its prediction time.
- Split by time when predicting the future, by group when entities repeat; test set touched once.
- Find disguised missing values (−1, 0, 999, "N/A"); ask *why* missing; add indicators when it may be informative.
- Drop direct identifiers, HMAC join keys, coarsen quasi-identifiers (age band, district); check the smallest group.
- Standardize before anything iterative or regularized; trees need no scaling.
- Report validation RMSE and $R^2$ next to the mean baseline and a one-rule model.

## Pitfalls
- Choosing on the test set; reporting the best of many test scores.
- Fitting a scaler, imputer, encoder or selector on all rows (selection on 5,000 noise columns: AUC 0.88 instead of 0.5).
- A feature recorded after the outcome; a random split for a forecasting problem; `CURRENT_DATE` in training SQL.
- Mean imputation without an indicator; the fill value computed with sentinels still in.
- Raw hour as a number (23 far from 0); one-hot without `handle_unknown`; dummy-variable trap without regularization.
- GD on raw features (κ = 5 × 10⁷ on diabetes); reading collinear or raw-unit weights as effects; weights as causes.

## Interview one-liners
- **Baseline:** the score of the simplest rule; a model that cannot beat it is not learning.
- **Leakage:** information unavailable at prediction time, or from the evaluation rows, reaching the model.
- **Train/serve skew:** a feature computed differently in training and serving; one code path fixes it.
- **Target encoding:** category → mean label, computed out of fold, or it copies the label.
- **AUC:** probability a random positive scores above a random negative.
- **Closed form vs GD:** exact and fast up to thousands of features; GD scales but needs scaling.
