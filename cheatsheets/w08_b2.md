# Week 08 cheat sheet: B2 Linear models & simple classifiers

## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Logistic model | $p = \sigma(z)$, $z = \mathbf{w}^\top\mathbf{x} + b$ = log-odds $\log\frac{p}{1-p}$; odds ratio $e^{w_j}$ | `(n,)` |
| Sigmoid slope | $\sigma'(z) = \sigma(z)(1 - \sigma(z)) \le \frac14$ | |
| Log-loss (stable) | $\ell = -[y\log p + (1-y)\log(1-p)] = \log(1 + e^z) - yz$ (`logaddexp`) | scalar |
| Its gradient | $\partial\ell/\partial z = p - y$; $\nabla_{\boldsymbol\theta} = \frac1n\mathbf{A}^\top(\mathbf{p} - \mathbf{y})$; at optimum mean $p$ = positive rate | `(d+1,)` |
| GD step bound | $L = \frac14\lambda_{\max}(\frac1n\mathbf{A}^\top\mathbf{A})$; $\eta = 1/L$ never overshoots | |
| Ridge (sklearn) | $\lVert\mathbf{y} - \mathbf{Z}\mathbf{w} - b\rVert^2 + \lambda\lVert\mathbf{w}\rVert^2$ → $(\mathbf{Z}^\top\mathbf{Z} + \lambda\mathbf{I})\mathbf{w} = \mathbf{Z}^\top(\mathbf{y} - \bar y)$, $b = \bar y$ | `(d,)` |
| Lasso (sklearn) | $\frac{1}{2n}\lVert\cdot\rVert^2 + \lambda\lVert\mathbf{w}\rVert_1$; coordinate step $w_j = S(a_j, \lambda)/c_j$, $S(a,t) = \operatorname{sign}(a)\max(\lvert a\rvert - t, 0)$ | |
| Elastic net | $\frac{1}{2n}\lVert\cdot\rVert^2 + \lambda\rho\lVert\mathbf{w}\rVert_1 + \frac{\lambda(1-\rho)}{2}\lVert\mathbf{w}\rVert^2$; $w_j = S(a_j, \lambda\rho)/(c_j + \lambda(1-\rho))$ | |
| Lasso path start | $\lambda_{\max} = \max_j\lvert\mathbf{z}_j^\top(\mathbf{y} - \bar y)\rvert/n$: all weights 0 at or above it | |
| MAP reading | L2 = Gaussian prior; L1 = Laplace prior $\frac{1}{2s}e^{-\lvert w\rvert/s}$ | |
| `LogisticRegression` / `SVC` C | $C\sum\ell_i + \frac12\lVert\mathbf{w}\rVert^2$ ⇔ mean loss $+ \frac{\lambda}{2}\lVert\mathbf{w}\rVert^2$, $\lambda = 1/(Cn)$ | |
| Distances | L2, L1, cosine $1 - \frac{\mathbf{u}^\top\mathbf{v}}{\lVert\mathbf{u}\rVert\lVert\mathbf{v}\rVert}$; unit vectors: $\lVert\mathbf{u} - \mathbf{v}\rVert^2 = 2 - 2\cos$ | |
| All pairs | $\mathbf{D}^{(2)} = \lVert\mathbf{q}\rVert^2 + \lVert\mathbf{x}\rVert^2 - 2\mathbf{Q}\mathbf{X}^\top$ | `(m, n)` |
| Concentration | uniform cube: $\mathbb{E}\lVert\mathbf{u}-\mathbf{v}\rVert^2 = d/6$, sd/mean $= 1.18/\sqrt d$; 1%-cube side $0.01^{1/d}$ | |
| Naive Bayes | $P(c \mid \mathbf{x}) \propto \pi_c\prod_w\theta_{cw}^{x_w}$; $\theta_{cw} = \frac{N_{cw} + \alpha}{N_c + \alpha V}$; normalize with log-sum-exp | `(K, V)` |
| NB log-odds | $\log\frac{\pi_1}{\pi_0} + \sum_w x_w\log\frac{\theta_{1w}}{\theta_{0w}}$: linear, weights by counting | |
| SVM | $\min \frac{\lambda}{2}\lVert\mathbf{w}\rVert^2 + \frac1n\sum\max(0, 1 - y_if_i)$, $y \in \{-1,+1\}$; margin width $2/\lVert\mathbf{w}\rVert$ | |
| SVM dual / kernel | $\mathbf{w} = \sum\alpha_iy_i\mathbf{x}_i$, $0 \le \alpha_i \le C$; $f(\mathbf{x}) = \sum_{\text{SV}}\alpha_iy_ik(\mathbf{x}_i, \mathbf{x}) + b$; RBF $e^{-\gamma\lVert\mathbf{x}-\mathbf{z}\rVert^2}$ | |

## Code
```python
make_pipeline(StandardScaler(), LogisticRegression())           # default C=1 (L2); C=np.inf = no penalty
LogisticRegression(C=0.1, l1_ratio=1.0, solver="saga")          # L1 (penalty= is deprecated in 1.9.1)
RidgeCV(alphas=np.logspace(-3, 3, 13)); LassoCV(); ElasticNetCV(l1_ratio=[.1, .5, .9, 1])
make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=5, weights="distance"))
make_pipeline(CountVectorizer(), MultinomialNB(alpha=0.3)); GaussianNB()
make_pipeline(StandardScaler(), SVC(kernel="rbf", C=1.0, gamma="scale"))   # decision_function = score
LinearSVC(loss="hinge")   # default is squared hinge + penalized intercept
np.logaddexp(0, z) - y * z; scipy.special.expit(z); scipy.special.logsumexp(S, axis=1)
```

## Defaults and rules of thumb
- Standardize (in a pipeline) before any penalty, distance or kernel; never penalize the intercept.
- Tune `C` / `alpha` / `k` / `gamma` on log grids by CV; report log-loss as well as accuracy.
- Lasso for sparsity, ridge for stability, elastic net for correlated groups; check lasso selection by bootstrap.
- kNN: few meaningful features; odd k; cosine for embeddings; approximate index at scale.
- NB: first text baseline; tune α (0.01–1); calibrate before using its probabilities.

## Pitfalls
- `log(sigmoid(z))` → `inf`/`nan`; 0/1 labels in a hinge; `predict_proba[:, 0]` instead of column 1.
- Perfect separation (train acc 1.0, huge weights) → keep a penalty; suspect leakage.
- `alpha` in `Ridge` (sum) ≠ `alpha` in `Lasso` (half-mean); `C` is the inverse strength.
- kNN on raw units (proline = half of every distance); noise features drown kNN (0.94 → 0.64).
- Reading lasso picks or NB probabilities as truth; kernel SVMs at millions of rows ($O(n^2)$).

## Interview one-liners
- **Logistic regression:** linear log-odds through a sigmoid, fitted by Bernoulli MLE (log-loss); gradient $(p - y)\mathbf{x}$.
- **L1 vs L2:** constant vs vanishing push to zero; sparse vs shrunk; Laplace vs Gaussian prior.
- **Curse of dimensionality:** distances concentrate; nearest ≈ farthest; neighbourhoods stop being local.
- **Naive Bayes:** independent features given the class; good argmax, overconfident probabilities.
- **Kernel trick:** dual needs only dot products; swap in $k(\mathbf{x}, \mathbf{z}) = \boldsymbol\phi(\mathbf{x})^\top\boldsymbol\phi(\mathbf{z})$, never compute $\boldsymbol\phi$.
