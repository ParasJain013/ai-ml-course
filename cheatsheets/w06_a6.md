## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Robust centre / spread | median; $\mathrm{IQR} = Q(0.75) - Q(0.25)$; $\mathrm{MAD} = \operatorname{median}\lvert x_i - \operatorname{median}\rvert$, $\hat\sigma = 1.4826\,\mathrm{MAD}$ | `(n,)` → scalar |
| Outlier flags | Tukey: outside $[Q_1 - 1.5\,\mathrm{IQR},\ Q_3 + 1.5\,\mathrm{IQR}]$; robust $z = (x - \operatorname{med})/(1.4826\,\mathrm{MAD}) > 3.5$ | |
| Correlation | Pearson $r = \frac{\sum(x - \bar x)(y - \bar y)}{(n-1)s_xs_y}$ (linear); Spearman = Pearson on ranks (monotone) | scalar |
| t interval | $\bar{x} \pm t_{0.975,\,n-1}\,s/\sqrt{n}$ | |
| Percentile bootstrap | resample $n$ with replacement $B$ times; 2.5th–97.5th percentiles of $\hat\theta^*$ | `(B,)` |
| Wilson (proportion) | $\frac{\hat p + z^2/2n \pm z\sqrt{\hat p(1-\hat p)/n + z^2/4n^2}}{1 + z^2/n}$ | |
| p-value | $P(\text{statistic at least as extreme} \mid H_0)$; uniform on [0, 1] under $H_0$ | |
| Permutation p | $(1 + \#\{\lvert T^*\rvert \ge \lvert T_{\text{obs}}\rvert\})/(1 + B)$, labels shuffled on the pooled data | |
| Welch t | $t = \frac{\bar x_B - \bar x_A}{\sqrt{s_A^2/n_A + s_B^2/n_B}}$ | |
| Chi-square | $\chi^2 = \sum(O - E)^2/E$, $E = \text{row}\times\text{col}/n$, df $(r-1)(c-1)$; $V = \sqrt{\chi^2/(n(\min(r,c) - 1))}$ | |
| Cohen's d | $(\bar x_B - \bar x_A)/s_{\text{pooled}}$; 0.2 / 0.5 / 0.8 small / medium / large | |
| Multiple tests | $P(\ge 1\text{ false}) = 1 - (1-\alpha)^m$; Bonferroni $\alpha/m$; Holm $\alpha/(m - k + 1)$; BH $p_{(k)} \le \frac{k}{m}\alpha$ | |
| Sample size / arm | $n = (z_{1-\alpha/2} + z_{1-\beta})^2\,(p_A q_A + p_B q_B)/\delta^2$; $(1.96 + 0.84)^2 = 7.85$ | half $\delta$ → 4× $n$ |
| Entropy | $H(p) = -\sum p\log p$; max $\log K$; bits $\log_2$, nats $\ln$ | |
| Cross-entropy / KL | $H(p, q) = -\sum p\log q = H(p) + D_{\mathrm{KL}}(p\,\|\,q)$; $D_{\mathrm{KL}} = \sum p\log\frac{p}{q} \ge 0$, not symmetric | |
| Mutual information | $I(X; Y) = H(Y) - H(Y \mid X) = D_{\mathrm{KL}}(p(x,y)\,\|\,p(x)p(y))$ | |
| Gaussian KL | $D_{\mathrm{KL}}(\mathcal{N}(\mu, \sigma^2)\,\|\,\mathcal{N}(0, 1)) = \frac12(\sigma^2 + \mu^2 - 1 - \log\sigma^2)$ | |
| Beta–Binomial | Beta($a$, $b$) + $k$ of $n$ → Beta($a + k$, $b + n - k$); mean $\frac{a+k}{a+b+n}$, mode $\frac{a+k-1}{a+b+n-2}$ | |
| Shrinkage | posterior mean $= w\frac{a}{a+b} + (1-w)\frac{k}{n}$, $w = \frac{a+b}{a+b+n}$; prior worth $a + b$ obs. | |

## Defaults and rules of thumb
- Report median and p95/p99 for skewed metrics; mean ± SE only for roughly symmetric data.
- Every number gets an interval; bootstrap the unit that is independent (users, not rows).
- Effect size + CI next to every p-value; Welch, not Student; fix $\alpha$, metric, $n$ before looking.
- One primary metric, guardrails, SRM check, whole weeks, one look (or a calibrated sequential plan).
- Beta(1, 1) knowing nothing; weak prior $a + b \approx 2$–10 on a historical rate; rank by posterior mean.

## Pitfalls
- Correlation without a plot (Anscombe); a pooled trend reversing in every segment (Simpson).
- Bootstrap with `replace=False`; small $n$ or extremes → percentile interval too narrow.
- "p = 0.03 → 97% sure it works"; big $n$ makes trivial effects significant; $p > 0.05$ ≠ no effect.
- Permuting within groups; 20 metrics without correction; peeking daily (≈ 25% false wins).
- KL with $q = 0$ where $p > 0$ is infinite; mixing bits and nats; $\log(\text{softmax})$ instead of log-softmax.
- Overconfident or post-hoc priors; stopping when $P(B > A)$ first crosses 0.95.

## Interview one-liners
- **Robust statistic:** barely moves when a few values are wild (median: breakdown 50%; mean: 0%).
- **Confidence interval:** a procedure covering the truth 95% of the time; credible: probability given prior.
- **p-value:** how surprising the data is if nothing changed; not P(null).
- **FDR:** expected share of false discoveries among rejections; BH controls it.
- **Cross-entropy loss:** NLL of the labels = KL to the label distribution + a constant.
- **Bayesian shrinkage:** small samples are pulled to the prior mean; large ones speak for themselves.
