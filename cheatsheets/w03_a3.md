# Week 03 cheat sheet: A3 Linear algebra II: decompositions

## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Eigenpair | $\mathbf{A}\mathbf{v} = \lambda\mathbf{v}$, $\mathbf{v} \ne \mathbf{0}$; solve $\det(\mathbf{A} - \lambda\mathbf{I}) = 0$ | $\mathbf{A}$ `(d, d)`, $\mathbf{v}$ `(d,)` |
| 2×2 eigenvalues | $\lambda^2 - \operatorname{tr}\,\lambda + \det = 0$; $\sum\lambda = \operatorname{tr}$, $\prod\lambda = \det$ | |
| Eigendecomposition | $\mathbf{A} = \mathbf{V}\boldsymbol{\Lambda}\mathbf{V}^{-1}$, $\mathbf{A}^k = \mathbf{V}\boldsymbol{\Lambda}^k\mathbf{V}^{-1}$; symmetric: $\mathbf{Q}\boldsymbol{\Lambda}\mathbf{Q}^\top$ | $\mathbf{Q}^\top\mathbf{Q} = \mathbf{I}$ |
| Power iteration | $\mathbf{x} \leftarrow \mathbf{A}\mathbf{x}/\lVert\mathbf{A}\mathbf{x}\rVert$; error $\times\lvert\lambda_2/\lambda_1\rvert$ per step | |
| Rayleigh quotient | $\lambda \approx \mathbf{x}^\top\mathbf{A}\mathbf{x}/\mathbf{x}^\top\mathbf{x}$ | scalar |
| Thin SVD | $\mathbf{A} = \mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^\top$, $\mathbf{A}\mathbf{v}_j = \sigma_j\mathbf{u}_j$, $\sigma_1 \ge \dots \ge 0$ | `(n, r)(r, r)(r, d)`, $r = \min(n, d)$ |
| SVD from eigen | $\mathbf{A}^\top\mathbf{A} = \mathbf{V}\boldsymbol{\Sigma}^2\mathbf{V}^\top$, $\sigma_j = \sqrt{\lambda_j}$, $\mathbf{u}_j = \mathbf{A}\mathbf{v}_j/\sigma_j$ | |
| Truncation | $\mathbf{A}_k = \sum_{j\le k}\sigma_j\mathbf{u}_j\mathbf{v}_j^\top$; $\lVert\mathbf{A} - \mathbf{A}_k\rVert_F^2 = \sum_{j>k}\sigma_j^2$; stores $k(n + d + 1)$ | best rank $k$ |
| Pseudo-inverse | $\mathbf{X}^+ = \mathbf{V}\boldsymbol{\Sigma}^+\mathbf{U}^\top$; $\mathbf{w} = \mathbf{X}^+\mathbf{y}$ = min-norm least squares | `(d, n)` |
| Covariance | $\mathbf{S} = \frac{1}{n-1}\mathbf{X}_c^\top\mathbf{X}_c$, $\mathbf{X}_c = \mathbf{X} - \bar{\mathbf{x}}$ | `(d, d)` |
| Variance along $\mathbf{w}$ | $\mathbf{w}^\top\mathbf{S}\mathbf{w} \ge 0$ (PSD); $\operatorname{Cov}(\mathbf{X}\mathbf{M}) = \mathbf{M}^\top\mathbf{S}\mathbf{M}$ | scalar; `(k, k)` |
| Correlation | $R_{jk} = S_{jk}/(s_js_k) \in [-1, 1]$ | `(d, d)` |
| Condition number | $\kappa = \sigma_{\max}/\sigma_{\min}$; $\frac{\lVert\delta\mathbf{x}\rVert}{\lVert\mathbf{x}\rVert} \le \kappa\frac{\lVert\delta\mathbf{b}\rVert}{\lVert\mathbf{b}\rVert}$; $\kappa(\mathbf{X}^\top\mathbf{X}) = \kappa(\mathbf{X})^2$ | |
| QR least squares | $\mathbf{X} = \mathbf{Q}\mathbf{R}$, solve $\mathbf{R}\mathbf{w} = \mathbf{Q}^\top\mathbf{y}$ by back substitution | $\mathbf{Q}$ `(n, d)`, $\mathbf{R}$ `(d, d)` |
| Cholesky | $\mathbf{C} = \mathbf{L}\mathbf{L}^\top$; $\ell_{jj} = \sqrt{c_{jj} - \sum_{k<j}\ell_{jk}^2}$; $\mathbf{L}\mathbf{y} = \mathbf{b}$, $\mathbf{L}^\top\mathbf{x} = \mathbf{y}$ | SPD only |

## Code
```python
vals, vecs = np.linalg.eigh(S)                  # symmetric: real, ascending, vecs[:, j] (columns!)
vals, vecs = np.linalg.eig(B)                   # general: complex dtype in NumPy 2.5; check .imag
U, s, Vt = np.linalg.svd(A, full_matrices=False)  # Vt rows are the v_j; s descending
A_k = (U[:, :k] * s[:k]) @ Vt[:k]               # rank-k truncation
S = np.cov(X, rowvar=False)                     # (d, d), ddof=1; np.cov(X) is (n, n)!
R = np.corrcoef(X, rowvar=False)
w, *_ = np.linalg.lstsq(X, y, rcond=None)       # SVD-based least squares, rank-deficient OK
x = np.linalg.solve(A, b); np.linalg.cond(A)    # never np.linalg.inv(A) @ b
c = scipy.linalg.cho_factor(C); x = scipy.linalg.cho_solve(c, b)
TruncatedSVD(n_components=k, random_state=SEED) # top k of a big/sparse matrix (does not center)
```

## Defaults and rules of thumb
- `eigh` for symmetric matrices; `eig` only otherwise. Align signs before comparing vectors.
- Pass `full_matrices=False`; plot singular values on a log scale; choose $k$ by the task.
- `rowvar=False` for `np.cov`/`np.corrcoef`; pass `ddof` explicitly (`np.var` 0, pandas 1).
- You lose about $\log_{10}\kappa$ digits (16 in float64, 7 in float32). Standardize features first.
- `solve` not `inv`; `lstsq`/QR not normal equations; Cholesky for SPD; jitter $\epsilon\mathbf{I}$ if needed.

## Pitfalls
- `vecs[0]` is a row, not an eigenvector; `Vt[:, :k]` is wrong, use `Vt[:k]`.
- Power iteration with $\lvert\lambda_2/\lambda_1\rvert \approx 1$ crawls; $= 1$ never converges. Cap and check.
- Energy fractions on uncentered data are dominated by the mean; a 90% rule can keep noise.
- Covariance magnitude depends on units; zero correlation ≠ independence.
- One-pass $\sum x^2 - n\bar{x}^2$ with a large offset: catastrophic cancellation, negative variance.
- A small residual from `solve` does not mean an accurate $\mathbf{x}$ when $\kappa$ is large.

## Interview one-liners
- **Eigenvector:** a direction the matrix only stretches; eigenvalue = the stretch.
- **SVD:** any matrix = rotate, scale, rotate; top-$k$ layers = best rank-$k$ approximation.
- **Covariance matrix:** pairwise co-movement; symmetric PSD; eigenvectors = axes of the data.
- **Condition number:** worst-case error amplification, $\sigma_{\max}/\sigma_{\min}$.
- **QR / Cholesky:** stable least squares / fast SPD solves and a PD test.
