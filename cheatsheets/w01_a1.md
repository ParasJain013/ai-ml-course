## Formulas
| Name | Formula | Shapes |
|---|---|---|
| Dot product | $\mathbf{a}\cdot\mathbf{b} = \sum_j a_j b_j$ | `(d,)`, `(d,)` → scalar |
| L2 / L1 norm | $\lVert\mathbf{a}\rVert_2 = \sqrt{\mathbf{a}\cdot\mathbf{a}}$, $\lVert\mathbf{a}\rVert_1 = \sum_j \lvert a_j\rvert$ | `(d,)` → scalar |
| Cosine similarity | $\frac{\mathbf{a}\cdot\mathbf{b}}{\lVert\mathbf{a}\rVert\lVert\mathbf{b}\rVert} \in [-1, 1]$; distance $= 1 - \cos$ | → scalar |
| Unit vectors | $\lVert\hat{\mathbf{a}} - \hat{\mathbf{b}}\rVert^2 = 2 - 2\cos$ | rankings agree |
| Pairwise distance | $D_{ij}^2 = \lVert\mathbf{a}_i\rVert^2 + \lVert\mathbf{b}_j\rVert^2 - 2\,\mathbf{a}_i\cdot\mathbf{b}_j$ | `(n, d)`, `(m, d)` → `(n, m)` |
| Standardize | $z_{ik} = (x_{ik} - \mu_k)/\sigma_k$, $\sigma$ with $1/n$ | `(n, d)` − `(d,)` |
| Join size | inner $= \sum_k n_L(k)\,n_R(k)$; left adds unmatched left rows | rows |
| Histogram | $h = (u - \ell)/k$, bin $= \min(\lfloor (x - \ell)/h \rfloor, k - 1)$, density $c_j/(nh)$ | `(n,)` → `(k,)` |
| Lie factor | (relative change drawn) / (relative change in data) | ≈ 1 when honest |
| LCG | $x_{k+1} = (a x_k + c) \bmod m$ | seed $= x_0$ |

## Defaults and rules of thumb
- `uv sync` after pulls; `uv run python labs/<P>/<file>.py`; never `pip install` in a lab.
- One `SEED`; `default_rng`, never `np.random.seed`; seed Python, NumPy and PyTorch separately.
- Rows are examples: `X` is `(n, d)`; `axis=0` collapses rows → one value per feature.
- Compare floats with `np.testing.assert_allclose(rtol=1e-6, atol=1e-8)`, never `==`.
- Bars start at 0; line charts may zoom if labelled; titles state the takeaway; axes have units.
- Histograms: start with `bins="auto"`, try others; log-x for skewed data.
- Store embeddings L2-normalized; search by inner product.

## Pitfalls
- `(n, 1) - (n,)` → `(n, n)`, no error. Assert shapes; use `keepdims=True`.
- Basic slices are views (writes go through); fancy/mask indexing makes copies.
- `np.std` divides by $n$, pandas `.std()` by $n - 1$.
- Norm trick loses precision far from the origin; clip negatives to 0 before `sqrt`.
- pandas: `groupby` drops NaN keys; all-NaN sum = 0 (`min_count=1`); left join turns int ids to float.
- Chained assignment `df[m]["c"] = v` does nothing in pandas 3; use `df.loc[m, "c"] = v`.
- An extra random draw shifts every later number in that stream.
- Cosine of a zero vector is undefined (`nan`); scipy's `cosine` is a *distance*.

## Interview one-liners
- **Broadcasting:** align shapes from the right; each axis must match or be 1; size-1 axes stretch.
- **Vectorization:** whole-array ops run in compiled code, 10–100× faster than Python loops.
- **Seed:** the starting state of a deterministic generator; same seed, same stream.
- **`COUNT(*)` vs `COUNT(col)`:** `size` vs `count` in pandas; NULLs count only in the first.
- **Lie factor:** visual effect ÷ data effect; truncated bar axes inflate it.
- **Cosine similarity:** direction only; for unit vectors it is the dot product.
