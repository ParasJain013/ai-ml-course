# Week 11 cheat sheet: B5 Unsupervised learning

## Formulas
| Name | Formula | Shapes |
|---|---|---|
| k-means objective (inertia) | $J = \sum_i \lVert\mathbf{x}_i - \mathbf{c}_{z_i}\rVert^2$; assign to nearest $\mathbf{c}_j$, then $\mathbf{c}_j = $ mean of its points | $\mathbf{X}$ `(n, d)`, $\mathbf{C}$ `(k, d)` |
| k-means++ | next centroid $= \mathbf{x}_i$ with prob. $D(\mathbf{x}_i)^2/\sum_l D(\mathbf{x}_l)^2$ | |
| Silhouette | $s_i = \frac{b_i - a_i}{\max(a_i, b_i)}$; $a$ = mean dist. to own cluster, $b$ = to nearest other; score = mean $s_i$; $O(n^2)$ | |
| ARI | $\frac{\text{index} - \mathbb{E}}{\text{max} - \mathbb{E}}$ over pairs, index $= \sum\binom{n_{uv}}{2}$; 1 same, ≈0 chance | |
| Linkage | single $\min$, complete $\max$ pair distance; Ward $\Delta = \frac{n_An_B}{n_A + n_B}\lVert\boldsymbol\mu_A - \boldsymbol\mu_B\rVert^2$, height $\sqrt{2\Delta}$ | |
| DBSCAN | core if $\lvert N_\varepsilon(\mathbf{x})\rvert \ge m$ (self incl.); cluster = connected cores + border; rest noise $-1$ | |
| GMM | $p(\mathbf{x}) = \sum_k \pi_k\mathcal{N}(\mathbf{x}\mid\boldsymbol\mu_k, \boldsymbol\Sigma_k)$ | $\boldsymbol\Sigma_k$ `(d, d)` |
| E-step | $\gamma_{ik} = \pi_k\mathcal{N}_k(\mathbf{x}_i)/\sum_j \pi_j\mathcal{N}_j(\mathbf{x}_i)$ (Bayes; in logs with log-sum-exp) | $\boldsymbol\Gamma$ `(n, K)` |
| M-step | $N_k = \sum_i\gamma_{ik}$, $\pi_k = N_k/n$, $\boldsymbol\mu_k = \frac{1}{N_k}\sum_i\gamma_{ik}\mathbf{x}_i$, $\boldsymbol\Sigma_k = \frac{1}{N_k}\sum_i\gamma_{ik}(\mathbf{x}_i - \boldsymbol\mu_k)(\cdot)^\top$ | |
| BIC | $-2\ell + p\log n$; full GMM $p = (K - 1) + Kd + Kd(d + 1)/2$; lower is better | |
| PCA | $\mathbf{X}_c = \mathbf{U}\boldsymbol\Sigma\mathbf{V}^\top$; PCs = columns of $\mathbf{V}$; $\lambda_j = \sigma_j^2/(n - 1)$; ratio $\sigma_j^2/\sum\sigma_i^2$ | $\mathbf{V}_k$ `(d, k)` |
| Scores / reconstruction | $\mathbf{Z} = \mathbf{X}_c\mathbf{V}_k$; $\hat{\mathbf{X}} = \mathbf{Z}\mathbf{V}_k^\top + \boldsymbol\mu$; $\lVert\mathbf{X} - \hat{\mathbf{X}}\rVert_F^2 = \sum_{j>k}\sigma_j^2$ | `(n, k)`, `(n, d)` |
| t-SNE affinities | $p_{j\mid i} \propto e^{-\lVert\mathbf{x}_i - \mathbf{x}_j\rVert^2/2\sigma_i^2}$, $\sigma_i$ s.t. $e^{H_i}$ (nats) = perplexity; $p_{ij} = \frac{p_{j\mid i} + p_{i\mid j}}{2n}$; $q_{ij} \propto (1 + \lVert\mathbf{y}_i - \mathbf{y}_j\rVert^2)^{-1}$; minimize $D_{\mathrm{KL}}(P\,\Vert\,Q)$ | $\mathbf{Y}$ `(n, 2)` |
| Isolation forest | $s = 2^{-E[h(\mathbf{x})]/c(\psi)}$, $c(m) = 2H(m - 1) - \frac{2(m - 1)}{m}$, $H(i) \approx \ln i + 0.5772$; $c(256) \approx 10.24$ | |
| Rules | $z = (x - \bar x)/\hat\sigma$, $\lvert z\rvert \le \sqrt{n - 1}$; fences $[Q_1 - 1.5\,\mathrm{IQR},\ Q_3 + 1.5\,\mathrm{IQR}]$ | |

## Defaults and rules of thumb
- Standardize (log-transform skewed spend/counts first) before any distance-based method; PCA/clustering fitted on training rows only.
- k-means: `n_init ≥ 10`; scan $k = 2..10$ with inertia, silhouette, bootstrap ARI; smallest stable, actionable $k$.
- DBSCAN: `min_samples` ≈ $2d$ (≥ 4–5), $\varepsilon$ from the bend of the sorted k-distance curve; HDBSCAN when densities differ.
- GMM: k-means init, `n_init` ≥ 5, `reg_covar` on, $K$ and covariance type by BIC; `"diag"` beyond ~20 features.
- PCA: choose $k$ by downstream CV; cumulative variance (90–95%) only as a start; components are rows of `components_`.
- t-SNE/UMAP: pictures only; try ≥ 3 perplexities / `n_neighbors` and seeds; never read sizes or inter-cluster gaps.
- Anomalies: threshold = review budget (top $B$); evaluate with AP and precision@budget plus bootstrap CIs; log reviewer verdicts.

## Pitfalls
- Comparing labels with `==` across runs; trusting one k-means run; silhouette compared across different scalings.
- Single-linkage chaining; one $\varepsilon$ for clusters of different density; hierarchical clustering on 100k rows ($O(n^2)$ memory).
- Choosing $K$ by likelihood (always rises); collapsed GMM components.
- PCA on mixed units ("PC1 explains 99.8%" = one big-unit feature); PCA before trees; dashboards reading "PC1" across refits.
- Clusters "found" in a t-SNE/UMAP plot; feeding t-SNE coordinates to a model.
- `contamination` treated as knowledge; z-score masking/swamping; per-feature rules over many features; unscaled k-NN scores.

## Interview one-liners
- **k-means:** coordinate descent on inertia; local minima → k-means++ and restarts.
- **ARI:** pair-counting agreement between two partitions, label-free, chance-corrected.
- **DBSCAN:** dense regions grow clusters; shape-free, finds noise, chooses the count; one global density.
- **EM:** E-step Bayes, M-step weighted MLE; likelihood never decreases; k-means is its hard limit.
- **PCA:** SVD of centred data; max variance = min reconstruction error; scale-sensitive.
- **t-SNE/UMAP:** keep neighbours, not distances or sizes; they draw clusters even in noise.
- **Isolation forest:** anomalies are isolated by few random splits; score normalized by $c(\psi)$.
