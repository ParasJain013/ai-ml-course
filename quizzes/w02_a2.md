    ```python

    b = np.array([3., 6.])
    print(np.linalg.matrix_rank(A), np.linalg.matrix_rank(np.column_stack([A, b])))
    try:
        print(np.linalg.solve(A, b))
    except np.linalg.LinAlgError as e:
    ```

15. `[A2.4]` Find the bugs (there are two). What happens when it runs on four points? Fix it.

    ```python
    def fit_line(x, y):
        """Least-squares line. x (n,), y (n,) -> (intercept, slope)."""
        X = np.column_stack([x, x])
        w = np.linalg.inv(X.T @ X) @ X.T @ y
        return w[0], w[1]
    ```
