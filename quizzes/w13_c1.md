**Code reading**

11. `[C1.3]` What does this print, and what is the bug if this were a training loop?

    ```python
    import torch

    w = torch.tensor(2.0, requires_grad=True)
    for _ in range(3):
        loss = (w * 3) ** 2
        loss.backward()
    print(w.grad.item())
    ```

12. `[C1.4]` What do the two `print` calls show?

    ```python
    import numpy as np

    z = np.array([90.0, 91.0], dtype=np.float32)
    e = np.exp(z)
    print(e / e.sum())
    z = z - z.max()
    e = np.exp(z)
    print(np.round(e / e.sum(), 4))
    ```

13. `[C1.2]` `X` is a batch of 2 inputs to a layer with 2 units and `D` is that layer's delta. Which printed matrix is
    $\mathbf{G}_{\mathbf{W}}$, and why did the shapes not catch the wrong one?

    ```python
    import numpy as np

    X = np.array([[1.0, 2.0], [3.0, 4.0]])
    D = np.array([[1.0, 0.0], [0.0, 2.0]])
    print(D.T @ X)
    print(X.T @ D)
    ```

14. `[C1.1]` What does this print, and what function does the network compute?

    ```python
    import numpy as np

    W1 = np.array([[1.0, -1.0]])
    b1 = np.array([0.0, 0.0])
    W2 = np.array([[1.0], [1.0]])
    for x in [-2.0, 0.5, 3.0]:
        h = np.maximum(np.array([[x]]) @ W1 + b1, 0)
        print(x, (h @ W2).item())
    ```

15. `[C1.4]` What do the two lines print (roughly), and which one is a bug?

    ```python
    import torch
    import torch.nn.functional as F

    logits = torch.tensor([[2.0, 1.0, 0.0]])
    y = torch.tensor([0])
    print(round(F.cross_entropy(logits, y).item(), 4))
    print(round(F.cross_entropy(torch.softmax(logits, dim=1), y).item(), 4))
    ```
