14. `[B1.4]` The features and labels below are pure noise. Roughly what does this print? Explain the number and fix
    the code.

    ```python
    import numpy as np
    from sklearn.linear_model import LogisticRegression
    from sklearn.model_selection import cross_val_score

    rng = np.random.default_rng(0)
    X = rng.normal(size=(100, 5000))
    y = rng.integers(0, 2, 100)
    corr = np.abs([np.corrcoef(X[:, j], y)[0, 1] for j in range(5000)])
    top = np.argsort(corr)[-20:]
    print(round(cross_val_score(LogisticRegression(max_iter=1000), X[:, top], y, cv=5).mean(), 2))
    ```

15. `[B1.5]` What happens to `w`? Compute the largest stable learning rate, roughly, from the Hessian $\frac{2}{n}\mathbf{A}^\top\mathbf{A}$.

    ```python
    import numpy as np

    A = np.array([[1, 100.0], [1, 200.0], [1, 300.0]])
    y = np.array([1.0, 2.0, 3.0])
    w = np.zeros(2)
    for _ in range(50):
        w -= 0.01 * 2 / 3 * A.T @ (A @ w - y)
    print(w)
    ```
