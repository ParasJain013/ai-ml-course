12. `[A5.2]` The intent is 100,000 samples with covariance `Sigma`. What does this print (to 1 decimal)?
    Find the bug and explain the result.

    ```python
    rng = np.random.default_rng(0)
    Sigma = np.array([[4.0, 2.0], [2.0, 2.0]])
    L = np.linalg.cholesky(Sigma)
    Z = rng.standard_normal((100_000, 2))
    X = Z @ L
    print(np.round(np.cov(X, rowvar=False), 1))
    ```

13. `[A5.3]` What does this print (to 2 decimals)? Name the two quantities in words.

    ```python
    rng = np.random.default_rng(0)
    sick = rng.random(1_000_000) < 0.001
    pos = np.where(sick, True, rng.random(1_000_000) < 0.01)
    print(round(sick[pos].mean(), 2), round(pos[sick].mean(), 2))
    ```

14. `[A5.4]` What does this print, approximately? Explain both numbers from a formula.

    ```python
    rng = np.random.default_rng(0)
    for n in (100, 10_000):
        est = [rng.random(n).mean() for _ in range(1000)]
        print(n, round(np.std(est), 3))
    ```
