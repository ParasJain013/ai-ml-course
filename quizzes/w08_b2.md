14. `[B2.4]` What does this print? Compute the first value by hand, and explain the second and third.

    ```python
    from sklearn.feature_extraction.text import CountVectorizer
    from sklearn.naive_bayes import MultinomialNB

    docs = ["win cash now", "win a prize", "lunch now", "see you at lunch"]
    y = [1, 1, 0, 0]
    cv = CountVectorizer()
    nb = MultinomialNB().fit(cv.fit_transform(docs), y)
    for msg in ["win lunch", "win win win lunch", "a a a"]:
        print(msg, round(nb.predict_proba(cv.transform([msg]))[0, 1], 3))
    ```

15. `[B2.5]` What do the two lines print, and why are they the same?

    ```python
    import numpy as np
    from sklearn.svm import SVC

    X = np.array([[0, 0], [1, 0], [2, 2], [3, 2], [5, 5]], dtype=float)
    y = np.array([-1, -1, 1, 1, 1])
    a = SVC(kernel="linear", C=1e6).fit(X, y)
    b = SVC(kernel="linear", C=1e6).fit(X[[1, 2, 3]], y[[1, 2, 3]])
    print(np.round(a.coef_, 3), np.round(a.intercept_, 3), a.support_)
    print(np.round(b.coef_, 3), np.round(b.intercept_, 3))
    ```
