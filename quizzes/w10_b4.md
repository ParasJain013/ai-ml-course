14. `[B4.4]` The first block prints `validation recall: 1.0`; the second prints `validation recall, split first: 0.694`. Explain the difference: what is the bug in the first block?

    ```python
    import numpy as np
    from sklearn.datasets import make_classification
    from sklearn.model_selection import train_test_split
    from sklearn.tree import DecisionTreeClassifier

    X, y = make_classification(n_samples=5000, weights=[0.98], flip_y=0.02, random_state=0)
    rng = np.random.default_rng(0)
    pos = np.flatnonzero(y == 1)
    extra = rng.choice(pos, size=(y == 0).sum() - len(pos), replace=True)  # oversample to 50/50
    X_bal, y_bal = np.r_[X, X[extra]], np.r_[y, y[extra]]
    X_tr, X_va, y_tr, y_va = train_test_split(X_bal, y_bal, test_size=0.25, random_state=0, stratify=y_bal)
    tree = DecisionTreeClassifier(random_state=0).fit(X_tr, y_tr)
    print("validation recall:", round((tree.predict(X_va)[y_va == 1] == 1).mean(), 3))

    X_tr2, X_va2, y_tr2, y_va2 = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
    pos2 = np.flatnonzero(y_tr2 == 1)
    extra2 = rng.choice(pos2, size=(y_tr2 == 0).sum() - len(pos2), replace=True)
    tree2 = DecisionTreeClassifier(random_state=0).fit(np.r_[X_tr2, X_tr2[extra2]], np.r_[y_tr2, y_tr2[extra2]])
    print("validation recall, split first:", round((tree2.predict(X_va2)[y_va2 == 1] == 1).mean(), 3))
    ```
