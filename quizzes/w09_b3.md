11. `[B3.1]` What does this print? Explain each line.

    ```python
    import numpy as np


    def gini(counts):
        p = np.asarray(counts) / np.sum(counts)
        return 1 - np.sum(p**2)


    parent = [10, 10]
    for left, right in [([10, 0], [0, 10]), ([5, 5], [5, 5]), ([9, 1], [1, 9])]:
        n_l, n_r = sum(left), sum(right)
        w = (n_l * gini(left) + n_r * gini(right)) / (n_l + n_r)
        print(round(gini(parent) - w, 4))
    ```

13. `[B3.3]` This boosting loop has one bug. Find it, and describe what the training MSE does over the 100 rounds (it
    is printed after rounds 1, 5, 10, 20, 50 and 100).

    ```python
    import numpy as np
    from sklearn.tree import DecisionTreeRegressor

    rng = np.random.default_rng(0)
    X = rng.uniform(0, 10, size=(500, 1))
    y = np.sin(X[:, 0]) * 3 + rng.normal(0, 0.3, 500)

    F = np.full(len(y), y.mean())
    residual = y - F
    for m in range(100):
        tree = DecisionTreeRegressor(max_depth=3, random_state=0).fit(X, residual)
        F += 0.1 * tree.predict(X)
        if m + 1 in (1, 5, 10, 20, 50, 100):
            print(m + 1, round(float(np.mean((y - F) ** 2)), 3))
    ```

        return 3 * A[:, 0]  # the model ignores column 1
