13. `[B5.6]` What does this print? What does it tell you about `contamination`?

    ```python
    import numpy as np
    from sklearn.ensemble import IsolationForest

    X = np.random.default_rng(0).normal(size=(200, 3))
    f1 = IsolationForest(contamination=0.05, random_state=0).fit(X)
    f2 = IsolationForest(contamination=0.20, random_state=0).fit(X)
    print((f1.predict(X) == -1).sum(), (f2.predict(X) == -1).sum(),
          np.allclose(f1.score_samples(X), f2.score_samples(X)))
    ```
