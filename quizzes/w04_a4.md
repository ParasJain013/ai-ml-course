13. `[A4.3]` This backward pass for $f = x\cdot y + x$ is wrong. What does it print, what should it print,
    and which line is the bug?

    ```python
    x, y = 2.0, 3.0
    a = x * y
    f = a + x
    grads = {"f": 1.0}
    grads["a"] = grads["f"] * 1.0
    grads["x"] = grads["f"] * 1.0      # from f = a + x
    grads["x"] = grads["a"] * y        # from a = x * y
    grads["y"] = grads["a"] * x
    print(grads["x"], grads["y"])
    ```

14. `[A4.4]` What does this print? Why does $w$ neither converge nor diverge?

    ```python

    print(ws)
    ```
