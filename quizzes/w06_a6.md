13. `[A6.3a]` The intent is a permutation test for a difference in means. The second number printed is the
    standard deviation of the null distribution. What is it, what p-value would this code report, and what is
    the fix?

    ```python
    rng = np.random.default_rng(0)
    a = rng.normal(0.0, 1.0, 40)
    b = rng.normal(0.8, 1.0, 40)
    obs = b.mean() - a.mean()
    null = []
    for _ in range(2000):
        rng.shuffle(a)
        rng.shuffle(b)
        null.append(b.mean() - a.mean())
    print(round(obs, 3), round(np.std(null), 3))
    ```
