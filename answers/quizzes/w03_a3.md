## Part 1: Self-test

1. **$\mathbf{A}\mathbf{v} = \lambda\mathbf{v}$ with $\mathbf{v} \ne \mathbf{0}$: the matrix only stretches (or flips) $\mathbf{v}$, by
   the factor $\lambda$.** The zero vector satisfies $\mathbf{A}\mathbf{0} = \lambda\mathbf{0}$ for every $\lambda$, so
   allowing it would make every number an eigenvalue. $\mathbf{A}(3\mathbf{v}) = 3\mathbf{A}\mathbf{v} = 3\lambda\mathbf{v} = \lambda(3\mathbf{v})$:
   an eigenvector is really a direction. *Revisit: A3.1.*
2. **The ratio $\lvert\lambda_2/\lambda_1\rvert$ of the two largest eigenvalues in absolute value: the error
   shrinks by about that factor per step.** Close to 1 is slow; equal to 1 never converges, for example
   $\begin{pmatrix}2&0\\0&-2\end{pmatrix}$ (the vector's two parts keep the same relative size and the sign of one
   flips each step), or a rotation, which has no real eigenvector at all. *Revisit: A3.1.*
3. **$\mathbf{A}^\top\mathbf{A} = \mathbf{V}\boldsymbol{\Sigma}^2\mathbf{V}^\top$: the right singular vectors are the
   eigenvectors of $\mathbf{A}^\top\mathbf{A}$ and $\sigma_j = \sqrt{\lambda_j}$.** Singular values are lengths
   ($\sigma_j = \lVert\mathbf{A}\mathbf{v}_j\rVert$), and the eigenvalues of $\mathbf{A}^\top\mathbf{A}$ are
   $\lVert\mathbf{A}\mathbf{v}_j\rVert^2 \ge 0$; by convention the non-negative root is taken (any sign can be
   moved into $\mathbf{u}_j$). *Revisit: A3.2.*
4. **$\mathbf{w}^\top\mathbf{S}\mathbf{w} = \frac{1}{n-1}\lVert\mathbf{X}_c\mathbf{w}\rVert^2 \ge 0$: it is the variance of the data
   along $\mathbf{w}$, an average of squares.** It is singular exactly when some non-zero combination of
   features is constant on the data: a feature that is a linear combination of others (including a
   constant column), or $n \le d$. *Revisit: A3.3.*
5. **Conditioning is the problem's sensitivity to small input changes, whatever the algorithm; stability is
   whether the algorithm adds error beyond that.** Ill-conditioned problem: solving a Hilbert system or a
   regression with two nearly identical columns, where even exact arithmetic on rounded inputs moves the
   answer a lot. Unstable algorithm: the normal equations (they square $\kappa$), `inv(A) @ b`, classical
   Gram–Schmidt, or the one-pass variance formula on data with a large offset. *Revisit: A3.4.*
6. **$\lambda = 3$ with $\mathbf{v} = (1, 0)$; $\lambda = 2$ with $\mathbf{v} = (1, -1)$. Not orthogonal
   ($1 \cdot 1 + 0 \cdot (-1) = 1$), because the matrix is not symmetric.** For a triangular matrix the
   eigenvalues are the diagonal entries ($\operatorname{tr} = 5$, $\det = 6$, $(\lambda - 3)(\lambda - 2)$). For 3:
   $\mathbf{A} - 3\mathbf{I} = \begin{pmatrix}0&1\\0&-1\end{pmatrix}$ forces $v_2 = 0$. For 2: $\begin{pmatrix}1&1\\0&0\end{pmatrix}$ gives
   $v_1 + v_2 = 0$. *Revisit: A3.1.*
7. **`U` `(1000, 50)`, `s` `(50,)`, `Vt` `(50, 50)`; without the flag `U` is `(1000, 1000)`. Rank 10 stores
   $10 \times (1000 + 50 + 1) = 10{,}510$ numbers, 21.0% of $50{,}000$.** *Revisit: A3.2.*
8. **Rank 3; $\lVert\mathbf{A}\rVert_F = \sqrt{25 + 9 + 1} = \sqrt{35} \approx 5.916$; rank-1 error
   $\sqrt{9 + 1 + 0} = \sqrt{10} \approx 3.162$; relative error $\sqrt{10/35} \approx 0.535$; condition number
   infinite (the smallest singular value is 0: the matrix is singular).** *Revisit: A3.2, A3.4.*
9. **$\mathbf{S} = \begin{pmatrix}4&3\\3&3\end{pmatrix}$, correlation $3/\sqrt{12} \approx 0.866$, variance of $x_1 - x_2$ is 1.**
   Means $(2, 2)$; centered rows $(-2, -1), (0, -1), (2, 2)$; sums of products $8, 6, 6$, divided by 2.
   $\mathbf{w} = (1, -1)$: $\mathbf{w}^\top\mathbf{S}\mathbf{w} = 4 - 3 - 3 + 3 = 1$. Directly: $x_1 - x_2 = (-1, 1, 0)$, mean 0,
   sum of squares 2, divided by 2: 1 ✓. *Revisit: A3.3.*
10. **(a) $\mathbf{L} = \begin{pmatrix}2&0\\3&4\end{pmatrix}$ ($\ell_{11} = 2$, $\ell_{21} = 6/2 = 3$, $\ell_{22} = \sqrt{25 - 9} = 4$).
    (b) $\kappa = 10^6$: lose about 6 digits, so about 10 correct digits in float64 and about 1 in float32

11. **Prints:**

    `np.linalg.eig` returns complex arrays in the pinned NumPy even for real eigenvalues. The bug is
    `v = vecs[0]`, which takes a *row*; eigenvectors are the *columns*. Fix: `v = vecs[:, 0]` (and take

12. **Prints `(4, 4) (3,) (3, 3)`, then `2`.** Without `full_matrices=False`, `U` is padded to `(4, 4)`. Only

    has rank 2: each row is $(0, 1, 2) + 3i\,(1, 1, 1)$, a combination of two vectors. *Revisit: A3.2.*
13. **`Vt[:, :k]` takes columns of $\mathbf{V}^\top$; the $\mathbf{v}_j$ are its *rows*.** With `(100, 40)` and $k = 5$ it
    raises `ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0 ... (size 40 is
    different from 5)`. It runs only for $k = 40$, where `Vt[:, :40]` is all of `Vt`, so it returns $\mathbf{A}$
    exactly and a full-rank test would pass while every truncation is broken. Fix:
    `U[:, :k] @ np.diag(s[:k]) @ Vt[:k]` (or `(U[:, :k] * s[:k]) @ Vt[:k]`). *Revisit: A3.2.*
14. **Prints:**

    ```text
    (3, 3)
    [[ 4.  8.]
     [ 8. 16.]]
    [ 0. 20.]
    ```

    `np.cov(X)` treats rows as variables, hence `(3, 3)`. With `rowvar=False` the covariance is correct.
    One eigenvalue is 0 (it may print as `-0.`): the second column is exactly twice the first, so the
    covariance matrix is singular, positive semi-definite but not positive definite. *Revisit: A3.3.*
15. **Prints `0.0 0.6666666666666666`.** The true variance is $2/3$. Each $x^2$ is about $10^{16}$, where

## Part 2: Interview questions

### 1. Explain eigenvectors and eigenvalues to an engineer, and give one place they matter in ML.

**Strong answer:** A square matrix is a transformation: it moves every vector somewhere else, usually
turning it. An eigenvector is a direction that the transformation does not turn; it only stretches,
shrinks or flips vectors along it, and the eigenvalue is that factor. If you know them, the matrix
becomes simple: in eigenvector coordinates it just scales each axis. They matter wherever a matrix is
applied repeatedly or describes spread: the eigenvectors of a covariance matrix are the directions the
data varies along most, with variances given by the eigenvalues, which is PCA; and repeated
multiplication by one matrix, as in an RNN or a Markov chain, is dominated by the largest eigenvalue.

**Weak answer:** "Eigenvalues are the solutions of $\det(\mathbf{A} - \lambda\mathbf{I}) = 0$, and eigenvectors are the
null space of $\mathbf{A} - \lambda\mathbf{I}$. They are used in PCA."

**Why the weak one fails:** it gives the computation, not the meaning, so it would not help the listener,
and "used in PCA" without saying *what* they represent there shows recall, not understanding.

**Follow-up an interviewer would ask:** "Why are the eigenvectors of a covariance matrix orthogonal, and
why does that matter?"

### 2. What is the SVD, and why is it so widely used? Name two applications.

**Strong answer:** Any matrix, of any shape, factors as $\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^\top$: a rotation, an
independent scaling of each axis by a non-negative singular value, and another rotation. Equivalently, it
writes the matrix as a sum of rank-1 layers sorted by importance. Keeping the top $k$ layers gives the
best possible rank-$k$ approximation, with an error you can compute from the dropped singular values.
It always exists and is computed stably, which is why libraries build on it. Applications: PCA (the SVD
of the centered data), low-rank compression and denoising, latent-factor recommenders, solving least
squares and finding rank and condition number (`lstsq`, `matrix_rank`, `cond`), and the low-rank idea
behind LoRA fine-tuning.

**Weak answer:** "It's a matrix factorization that reduces dimensionality, like PCA."

**Why the weak one fails:** it confuses one application with the decomposition itself, says nothing
about what the factors are, and gives no reason the SVD is preferred (optimal truncation, always exists,
numerically stable).

**Follow-up an interviewer would ask:** "How are the singular values related to the eigenvalues of
$\mathbf{A}^\top\mathbf{A}$, and why do libraries avoid computing $\mathbf{A}^\top\mathbf{A}$?"

### 3. How do you choose $k$ for a truncated SVD or PCA?

**Strong answer:** By what the reduced data is for. If it feeds a model, treat $k$ as a hyperparameter
and pick it by validation performance, for example the smallest $k$ within a tolerance of the best score.
If the goal is compression, set an acceptable reconstruction error on held-out data. Diagnostics help:
plot the singular values on a log scale and look for a clear gap; the cumulative explained-variance
curve shows what each $k$ keeps. But an explained-variance threshold alone can mislead: on uncentered
data the mean dominates it, and with noise spread over all directions a 90% rule keeps many noise
components. Also check stability: the chosen components should not change much on a bootstrap
resample.

**Weak answer:** "Keep 95% of the variance; that's the standard."

**Why the weak one fails:** it applies a rule of thumb without tying $k$ to the task, and ignores the
cases where the rule keeps noise or discards a low-variance but predictive direction.

**Follow-up an interviewer would ask:** "Can a direction with very little variance still be the most
useful one for predicting the target? Give an example."

### 4. Covariance versus correlation; when do you use each, and what does a correlation of 0 mean?

**Strong answer:** Covariance is the average product of the two features' deviations from their means.
Its sign tells you whether they move together, but its size is in the product of their units, so it
cannot be compared across pairs. Correlation divides by both standard deviations, so it is unitless and
between −1 and 1, and comparable. Use correlation to compare or report strength of linear association;
use covariance when you need the actual scale, as in a Gaussian model, PCA on features in the same units,
or the variance of a combination $\mathbf{w}^\top\mathbf{S}\mathbf{w}$. A correlation of 0 means no *linear* association;
the variables can still be strongly dependent (a U-shape), and it says nothing about causation either way.

**Weak answer:** "Correlation is normalized covariance. Zero correlation means the variables are
independent."

**Why the weak one fails:** the second sentence is false; independence implies zero correlation but not
the other way around. It also gives no guidance on when to use which.

**Follow-up an interviewer would ask:** "When would you use a rank correlation such as Spearman instead
of Pearson?"

### 5. "Covariance matrix is not positive definite". What could cause this, and what do you do?

**Strong answer:** A true sample covariance is always positive *semi*-definite, so the error has one of
two causes. Either the matrix is singular: some feature is a linear combination of others (duplicated or
derived columns, one-hot columns that sum to a constant), a column is constant, or there are no more rows
than features; then a zero eigenvalue is real. Or it is not a true sample covariance: computed pairwise
with missing values (pandas `.cov()` skips missing values per pair), assembled from separate estimates,
or damaged by rounding (one-pass formulas, float32), giving slightly negative eigenvalues. I would check
the eigenvalues with `eigvalsh`, the rank of the data, and how the matrix was built. Fixes: remove
redundant features; compute the covariance from complete, centered data; add a small jitter
$\epsilon\mathbf{I}$ and log it; use shrinkage (Ledoit–Wolf) when $n$ is small relative to $d$.

**Weak answer:** "Use `np.linalg.pinv`, or set the negative eigenvalues to zero and continue."

**Why the weak one fails:** it patches the symptom without finding out whether the data has a real
redundancy or the computation is wrong, and clipping eigenvalues to zero still leaves a matrix that
Cholesky rejects.

**Follow-up an interviewer would ask:** "Why does adding $\epsilon\mathbf{I}$ make it positive definite, and what
does it do to the eigenvalues?"

### 6. Why avoid computing a matrix inverse? What instead? When do you need it?

**Strong answer:** To solve $\mathbf{A}\mathbf{x} = \mathbf{b}$, computing $\mathbf{A}^{-1}$ first costs about three times
the arithmetic of one factor-and-solve and is less accurate: `solve` (LU with pivoting) is backward
stable, so its residual stays at rounding level, while `inv(A) @ b` has no such guarantee and its error
is typically larger. For least squares, use `lstsq` or QR rather than inverting $\mathbf{X}^\top\mathbf{X}$, which
also squares the condition number. For symmetric positive-definite matrices use Cholesky. For many
right-hand sides, factor once and reuse the factorization. You genuinely need entries of the inverse
rarely, for example the covariance of regression coefficients $\sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}$; even then
compute it from a factorization (`cho_solve` with the identity) or only the diagonal you need. Sparse
matrices are another reason: the inverse of a sparse matrix is usually dense.

**Weak answer:** "Inverting is $O(n^3)$, which is slow, so use `solve`."

**Why the weak one fails:** `solve` is also $O(n^3)$; the real reasons are the constant factor and,
mainly, accuracy. It shows the habit without the understanding.

**Follow-up an interviewer would ask:** "If `solve` returns a tiny residual, does that mean the answer is
accurate?" (No, not when the condition number is large.)

### 7. What is a condition number? How do you detect and fix an ill-conditioned linear regression?

**Strong answer:** For a matrix it is $\sigma_{\max}/\sigma_{\min}$, the worst-case factor by which a
relative change in the input is amplified in the solution; you lose about $\log_{10}\kappa$ significant
digits. In regression, symptoms are coefficients that are huge, have opposite signs on related features,
change a lot when you refit on slightly different data, or depend on feature units. To detect it, compute
`np.linalg.cond(X)` on the standardized design matrix, look at the correlation matrix and variance
inflation factors, and look at the smallest singular values and their right singular vectors, which tell
you *which* combination of features is nearly redundant. Fixes: standardize features, drop or combine
redundant ones, add ridge regularization, and use a stable solver (QR, SVD) rather than the normal
equations; if the model only needs predictions, ill-conditioning in the coefficients may not hurt them,
but it does hurt any interpretation.

**Weak answer:** "It means the matrix is nearly singular. Use regularization."

**Why the weak one fails:** it gives no measurement, no detection method, and a single fix without saying
why it helps or what it costs (bias).

**Follow-up an interviewer would ask:** "Why does standardizing features change the condition number but
not the predictions of ordinary least squares?"

### 8. An RNN multiplies by the same weight matrix every step. Why do gradients explode or vanish?

**Strong answer:** Ignoring the nonlinearity, the hidden state after $T$ steps contains $\mathbf{W}^T$
applied to the initial state, and backpropagation through time multiplies the gradient by $\mathbf{W}^\top$ (times
activation derivatives) once per step. Writing a vector in the eigenvector basis of $\mathbf{W}$, each
component is multiplied by $\lambda_j^T$. If the largest $\lvert\lambda_j\rvert$ is above 1 that component
grows exponentially (exploding gradients); if all are below 1 everything shrinks exponentially, so
gradients from early time steps vanish and the network cannot learn long-range dependencies. It is the
same mechanism as power iteration. Remedies include gradient clipping for explosion, careful
initialization (for example orthogonal matrices, whose eigenvalues all have absolute value 1), and gated
architectures like LSTMs and GRUs that give the gradient an additive path.

**Weak answer:** "Because of the chain rule: you multiply many small derivatives together, so the gradient
gets small."

**Why the weak one fails:** it only covers vanishing, does not involve the weight matrix or its
eigenvalues (the question asked for them), and gives no remedies.

**Follow-up an interviewer would ask:** "For a non-symmetric $\mathbf{W}$, are the eigenvalues enough, or do the
singular values matter too?" (Singular values bound the growth over a few steps; eigenvalues govern the
long run.)
